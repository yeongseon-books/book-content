# 바이브코딩을 위한 CS 수학 (3/10): 집합과 함수

이 글은 **바이브코딩을 위한 CS 수학** 시리즈의 3편입니다. 집합과 함수가 데이터 모델링과 API 설계에서 어떻게 쓰이는지 바이브코딩 관점에서 살펴봅니다.

---

데이터베이스 쿼리를 짤 때, 중복을 제거할 때, 함수의 입출력 범위를 정의할 때 — 이 모든 상황의 기저에는 집합과 함수의 개념이 있습니다. AI 도구가 SQL이나 파이썬 코드를 제안할 때 그 구조를 집합론 언어로 읽을 수 있으면 오류를 더 빠르게 발견할 수 있습니다.

집합은 "무엇이 허용되고 무엇이 빠지는지"를 명확하게 합니다. 함수는 입력과 출력의 관계를 정의합니다. 이 두 개념이 잡히면 타입 시스템, 데이터 파이프라인, API 계약을 훨씬 명확하게 설계할 수 있습니다.

> "집합은 경계를 만들고, 함수는 변환을 정의합니다. 이 두 가지가 데이터 모델의 뼈대입니다."

- 집합으로 API의 입출력 범위를 어떻게 정의할까요?

- AI가 제안한 데이터 변환 코드를 집합 언어로 검증하는 방법은?

## 집합 연산을 SQL로 읽기

집합 연산은 SQL의 기본 구조입니다. 교집합은 INNER JOIN, 합집합은 UNION, 차집합은 EXCEPT에 대응합니다.

### Before: 집합 개념 없이 중복 처리

```python
# 두 리스트에서 공통 요소 찾기 — O(n*m)
def find_common(a, b):
    result = []
    for x in a:
        if x in b:
            result.append(x)
    return result
```

### After: 집합 교집합으로 명확하게

```python
# 교집합 — O(n+m) 평균
def find_common(a, b):
    return list(set(a) & set(b))  # 집합 교집합

# SQL에서는
# SELECT * FROM a INNER JOIN b ON a.id = b.id
```

## 함수의 세 가지 성질

| 성질 | 정의 | 실무 의미 | 코드 예시 |
| --- | --- | --- | --- |
| 단사함수 | 서로 다른 입력 → 서로 다른 출력 | 해시 충돌 없는 ID 생성 | UUID, 해시함수 |
| 전사함수 | 출력 범위 = 공역 전체 | 모든 상태에 도달 가능 | 상태머신 설계 |
| 전단사함수 | 단사 + 전사 | 역함수 존재, 암호화/복호화 | 암호화 알고리즘 |

## 집합으로 API 계약 정의하기

타입 시스템은 집합론의 응용입니다. 입력 집합과 출력 집합을 명확히 정의하면 API 계약이 명확해집니다.

```python
from typing import Optional

# 입력 집합: 비어있지 않은 문자열
# 출력 집합: 0 이상의 정수 또는 None
def find_index(items: list[str], target: str) -> Optional[int]:
    """
    불변식: 반환값이 None이 아니면 items[반환값] == target
    입력 공역: len(target) > 0
    출력 공역: {0, 1, ..., len(items)-1} ∪ {None}
    """
    try:
        return items.index(target)
    except ValueError:
        return None
```

## AI 팁: 집합 언어로 AI 코드 검증하기

1. **"이 함수의 입력 집합과 출력 집합을 정의해줘"** — 타입과 범위를 명확히 합니다.
2. **"단사함수인지 확인해줘"** — ID 생성 함수의 충돌 가능성을 검증합니다.
3. **"집합 차이로 누락 데이터를 찾아줘"** — 데이터 검증에 차집합을 활용합니다.
4. **Python의 set 타입**은 수학적 집합 연산을 그대로 지원합니다.

## 처음 질문으로 돌아가기

- **집합 연산이 SQL과 어떻게 연결될까요?**
  INNER JOIN은 교집합, UNION은 합집합, EXCEPT는 차집합입니다. SQL 최적화는 집합 연산 최적화입니다.

- **단사함수, 전사함수는 실무에서 무슨 의미일까요?**
  단사함수는 충돌이 없는 매핑(ID 생성), 전단사함수는 역변환이 가능한 매핑(암호화)입니다.

- **멱집합이 권한 설계에서 왜 등장할까요?**
  n개의 권한에서 가능한 권한 조합은 2^n개입니다. 권한 시스템은 멱집합의 부분집합을 관리합니다.
