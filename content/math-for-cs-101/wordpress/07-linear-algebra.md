## 벡터와 행렬: 데이터의 수학적 표현

데이터는 벡터입니다. 특성이 n개인 데이터 포인트 하나는 n차원 벡터입니다. m개의 데이터 포인트는 m×n 행렬입니다.

### Before: 선형대수 없이 유사도 계산

```python
# 단순 절댓값 차이 — 차원 크기에 따라 스케일 달라짐
def similarity(a, b):
    return sum(abs(x - y) for x, y in zip(a, b))
```

### After: 코사인 유사도로 방향 비교

```python
import numpy as np

def cosine_similarity(a, b):
    """
    코사인 유사도: 벡터의 방향 유사성 측정
    크기에 무관 — 임베딩 비교에 적합
    """
    a, b = np.array(a), np.array(b)
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

v1 = [1, 2, 3]
v2 = [2, 4, 6]  # v1의 2배 — 방향 동일
v3 = [1, 0, -1]  # 다른 방향

print(cosine_similarity(v1, v2))  # 1.0 — 완전히 같은 방향
print(cosine_similarity(v1, v3))  # ~-0.27 — 다른 방향
```

## 선형 변환: 행렬 곱셈의 의미

| 행렬 연산 | 기하학적 의미 | AI/ML 활용 |
| --- | --- | --- |
| 행렬 곱셈 | 선형 변환 (회전, 확대) | 신경망 레이어 |
| 전치 행렬 | 행과 열 교환 | 배치 처리 |
| 역행렬 | 변환 되돌리기 | 선형 회귀 해 |
| 고유분해 | 주요 방향 추출 | PCA, 차원 축소 |

```python
import numpy as np

# 신경망의 한 레이어: y = Wx + b
W = np.random.randn(4, 3)  # 가중치 행렬 (출력 4개, 입력 3개)
x = np.array([1.0, 2.0, 3.0])  # 입력 벡터
b = np.zeros(4)  # 편향

y = W @ x + b  # 행렬-벡터 곱셈
print(y.shape)  # (4,)
```

## AI 팁: 선형대수를 AI와 함께 활용하기

1. **"이 임베딩 벡터들의 코사인 유사도를 계산해줘"** — 텍스트/이미지 유사도 검색에 활용합니다.
2. **"PCA로 차원을 줄여줘"** — numpy나 sklearn으로 고차원 데이터를 시각화합니다.
3. **"행렬 곱셈 순서가 왜 중요한지 설명해줘"** — 변환 합성의 비가환성을 이해합니다.
4. **numpy.linalg** 모듈로 역행렬, 고유값, SVD를 AI 도움으로 쉽게 계산할 수 있습니다.

## 처음 질문으로 돌아가기

- **벡터와 행렬이 데이터 표현에서 왜 핵심일까요?**
  데이터의 특성을 벡터로, 데이터셋을 행렬로 표현하면 선형대수 연산으로 효율적으로 처리할 수 있습니다.

- **코사인 유사도는 왜 텍스트 유사도에 쓰일까요?**
  문서 길이에 무관하게 내용의 방향(의미)를 비교합니다. 크기가 달라도 방향이 같으면 유사도 1입니다.

- **고유값과 고유벡터는 PCA에서 어떤 역할을 할까요?**
  공분산 행렬의 고유벡터가 주성분 방향이고, 고유값이 그 방향의 분산(중요도)입니다.
