# 바이브코딩을 위한 CS 수학 (6/10): 확률

이 글은 **바이브코딩을 위한 CS 수학** 시리즈의 6편입니다. 확률이 AI 모델 출력 해석, A/B 테스트, 리스크 분석에서 어떻게 활용되는지 바이브코딩 관점에서 살펴봅니다.

---

AI 모델이 "이 이미지는 고양이일 확률 0.93입니다"라고 출력할 때, 그 0.93을 어디까지 믿어야 할까요? 바이브코딩으로 AI 도구를 활용하다 보면 확률 값과 끊임없이 마주칩니다. 분류 점수, 신뢰 구간, A/B 테스트 p-값 — 이것들을 제대로 해석하려면 확률의 기본 구조가 필요합니다.

확률은 불확실성을 숫자로 표현하는 언어입니다. 0과 1 사이 값이고, 전체 합은 1이어야 합니다. 이 단순한 규칙에서 AI 모델 평가와 통계적 의사결정이 시작됩니다.

> "확률은 불확실성을 숫자로 표현하는 언어입니다. AI 출력을 제대로 읽으려면 이 언어의 문법이 필요합니다."

## 이 글에서 다룰 질문들

- 조건부 확률과 베이즈 정리는 AI 추론과 어떻게 연결될까요?
- 독립 사건과 종속 사건은 특성 엔지니어링에 어떤 영향을 줄까요?
- 기대값과 분산은 모델 성능 지표를 어떻게 해석하게 할까요?
- A/B 테스트 결과를 확률로 어떻게 해석할까요?
- AI 모델의 0.93이라는 점수를 어디까지 믿어야 할까요?

## 조건부 확률과 베이즈 정리

```python
# 베이즈 정리: P(A|B) = P(B|A) * P(A) / P(B)
def bayes_update(prior, likelihood, evidence):
    """
    prior: P(A) — 사전 확률
    likelihood: P(B|A) — 우도
    evidence: P(B) — 증거 확률
    returns: P(A|B) — 사후 확률
    """
    return (likelihood * prior) / evidence

# 스팸 필터 예시
p_spam = 0.2          # 메일이 스팸일 사전 확률
p_word_given_spam = 0.8   # 스팸 메일에 특정 단어가 있을 확률
p_word = 0.3          # 해당 단어가 나타날 전체 확률

p_spam_given_word = bayes_update(p_spam, p_word_given_spam, p_word)
print(f"단어 존재시 스팸 확률: {p_spam_given_word:.2%}")  # 53.33%
```

### Before: 확률 기초 없이 AI 출력 해석

```python
score = model.predict_proba(data)[0][1]
print(f"스팸: {score:.2%}")  # 그냥 숫자로만 봄
# 사전 확률을 고려하지 않음
```

### After: 기저율을 감안한 해석

```python
# 모델 점수는 조건부 확률 추정값
# 실제 해석에는 기저율(prior)을 함께 봐야 함
score = model.predict_proba(data)[0][1]
base_rate = 0.02  # 실제 스팸 비율 2%
# 모델이 0.9를 출력해도 기저율이 낮으면 실제 확률은 낮을 수 있음
```

## 확률 분포와 기대값

| 분포 | 매개변수 | 실무 활용 | 주요 특성 |
| --- | --- | --- | --- |
| 이항분포 | n, p | A/B 테스트 성공 횟수 | 이산, 합이 항상 n |
| 정규분포 | μ, σ | 오차 분포, 성능 지표 | 연속, 중심극한정리 |
| 포아송분포 | λ | 단위 시간당 이벤트 수 | 이산, 요청 수 모델링 |
| 균등분포 | a, b | 랜덤 샘플링 | 연속, 모든 값 동일 확률 |

## AI 팁: 확률을 AI와 함께 활용하기

1. **"이 모델 출력의 기저율은 얼마야?"** — 사전 확률 없이는 점수 해석이 불완전합니다.
2. **"A/B 테스트 결과의 통계적 유의성을 계산해줘"** — p-값과 신뢰구간을 함께 확인합니다.
3. **"이 확률 분포가 데이터에 맞는지 검정해줘"** — 모델 가정을 검증합니다.
4. **scipy.stats**로 다양한 확률 분포 계산을 AI와 함께 수행할 수 있습니다.

## 처음 질문으로 돌아가기

- **조건부 확률과 베이즈 정리는 AI 추론과 어떻게 연결될까요?**
  AI 분류 모델의 출력은 P(클래스|입력)인 조건부 확률입니다. 베이즈 정리로 사전 확률을 반영한 사후 확률로 업데이트할 수 있습니다.

- **AI 모델의 0.93이라는 점수를 어디까지 믿어야 할까요?**
  모델 보정(calibration) 상태와 기저율을 함께 확인해야 합니다. 0.93이 실제 빈도 93%를 의미하지 않을 수 있습니다.

- **A/B 테스트 결과를 확률로 어떻게 해석할까요?**
  p-값은 귀무가설 하에서 이 결과가 나올 확률입니다. 단독으로 보지 않고 효과 크기와 신뢰구간을 함께 봐야 합니다.
