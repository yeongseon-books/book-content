# 바이브코딩을 위한 CS를 위한 수학 (8/10): 미분

이 글은 "바이브코딩을 위한 CS를 위한 수학" 시리즈의 8번째 글입니다.

---

바이브코딩에서 AI는 머신러닝 학습 코드와 최적화 알고리즘을 빠르게 만들어 줍니다. 그런데 손실 함수가 왜 줄어드는지, 학습률을 왜 조정해야 하는지, 그래디언트가 무엇인지 이해하지 못하면 AI가 만들어 준 코드의 하이퍼파라미터를 제대로 조정할 수 없습니다.

머신러닝 모델을 학습할 때 손실 함수를 줄이는 과정, 수치 최적화에서 더 좋은 해를 찾는 과정은 모두 한 질문으로 모입니다. 지금 위치에서 어느 방향으로 움직여야 하는가 하는 질문입니다.

미분은 바로 그 방향 감각을 주는 도구입니다. 미분은 복잡한 곡선을 전부 이해하게 만들기보다, 지금 이 지점의 변화 경향을 알려 줍니다. 변수가 하나면 기울기이고, 변수가 여러 개면 각 방향의 변화율을 모은 것이 그래디언트입니다.

극한, 도함수, 그래디언트, 연쇄 법칙, 경사하강법을 하나의 흐름으로 정리합니다.

> **핵심 인사이트:** 미분은 "지금 이 지점에서 어느 방향으로 움직여야 손실이 줄어드는가"를 알려 주는 도구입니다. 경사하강법은 그 정보를 반복적으로 써서 최적해에 다가갑니다. 학습률이 너무 크면 발산하고, 너무 작으면 수렴이 느립니다.

## 이 글에서 다룰 문제

- 변화량을 왜 한 점의 기울기로 요약할 수 있을까요?
- 극한과 도함수는 어떤 관계를 가질까요?
- 기울기와 그래디언트는 무엇이 다를까요?
- 경사하강법은 어떤 원리로 동작할까요?
- AI가 만든 최적화 코드에서 확인해야 할 것은 무엇인가요?

## 미분과 경사하강법 핵심 패턴

```python
# 수치 미분: 해석적 미분이 어려울 때 변화율 근사
def deriv(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

# 그래디언트: 여러 변수 각각의 편미분
def grad(f, x, h=1e-5):
    return [(f([xi + (h if i == j else 0) for i, xi in enumerate(x)])
             - f([xi - (h if i == j else 0) for i, xi in enumerate(x)])) / (2 * h)
            for j in range(len(x))]
```

```python
# 경사하강법: 그래디언트 반대 방향으로 이동
def gradient_descent(f, x_init, lr=0.01, steps=100):
    x = x_init[:]
    for step in range(steps):
        g = grad(f, x)
        x = [xi - lr * gi for xi, gi in zip(x, g)]
    return x

# 사용 예시: f(x, y) = x^2 + y^2 최솟값 찾기
def loss(x):
    return x[0]**2 + x[1]**2

result = gradient_descent(loss, [3.0, 4.0], lr=0.1, steps=50)
# result ≈ [0.0, 0.0] (최솟값)
```

## 변경 전후 비교

**Before: 미분 없이 최적화**
```text
- 손실 함수를 직접 보고 최솟값을 추측
- 하이퍼파라미터(학습률)를 이해 없이 랜덤하게 조정
- 모델이 수렴하지 않거나 발산해도 원인 파악 불가
- 그래디언트가 0인 지점과 최솟값을 혼동
```

**After: 미분 이해 후**
```text
- 그래디언트 크기로 학습 속도 조정 가능
- 학습률이 너무 크면 발산, 너무 작으면 느린 수렴 이해
- Local minimum vs global minimum 구분
- 연쇄 법칙으로 역전파 동작 원리 이해
```

## 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 방법 |
|------|-------------|-----------|
| 학습률을 너무 크게 설정 | 손실이 줄지 않고 발산 | 작은 값(0.001~0.01)에서 시작해 조정 |
| 수치 미분의 h 값 부적절 | h가 너무 크면 부정확, 너무 작으면 수치 오차 | h=1e-5 전후로 실험 |
| 그래디언트와 기울기를 혼동 | 다변수 함수에서 오해 발생 | 그래디언트는 편미분의 벡터 |
| Local minimum에 갇힘 | 전역 최솟값이 아닌 지역 최솟값 수렴 | 여러 초기값 시도, 모멘텀 사용 |
| 연쇄 법칙 없이 역전파 구현 | 다층 신경망에서 그래디언트 계산 불가 | 역전파 = 연쇄 법칙의 체계적 적용 |

## AI 활용 팁

```
# AI에게 이렇게 요청하세요:
"경사하강법으로 선형 회귀 모델을 학습하는 코드를 만들어줘.
MSE 손실 함수,
그래디언트 계산 과정 주석 포함,
학습률과 반복 횟수 파라미터화,
손실 곡선 출력"

# AI 결과물 검증 체크포인트:
# - 학습률이 적절한 범위인가? (0.001~0.1)
# - 그래디언트를 손실 함수의 편미분으로 올바르게 계산하는가?
# - 경사하강법 업데이트 방향이 맞는가? (그래디언트 반대 방향)
# - 학습이 발산하는지 손실 곡선으로 확인하는가?
# - 수치 안정성을 위한 처리가 있는가?
```

## 운영 체크리스트

- [ ] 학습률(learning rate)의 효과를 이해하고 적절히 설정한다
- [ ] 그래디언트 소실/폭발 문제 징후를 인식할 수 있다
- [ ] 손실 곡선으로 학습 수렴 여부를 확인한다
- [ ] 수치 미분으로 그래디언트 구현 검증(gradient check)을 한다
- [ ] 연쇄 법칙이 역전파에 어떻게 적용되는지 설명할 수 있다

## 처음 질문으로 돌아가기

- **도함수란?** 함수의 각 점에서 순간 변화율(기울기)을 나타내는 함수입니다. f'(x) = lim(h→0) [f(x+h) - f(x)] / h로 정의합니다.
- **그래디언트와 기울기의 차이는?** 기울기는 일변수 함수의 미분값입니다. 그래디언트는 다변수 함수에서 각 변수에 대한 편미분을 벡터로 모은 것입니다.
- **경사하강법 원리는?** 현재 위치에서 그래디언트(가장 가파른 상승 방향)의 반대로 학습률만큼 이동합니다. 이를 반복하면 손실 함수의 최솟값에 수렴합니다.
