# 바이브코딩을 위한 CS를 위한 수학 (9/10): 정보이론

이 글은 "바이브코딩을 위한 CS를 위한 수학" 시리즈의 9번째 글입니다.

---

바이브코딩에서 AI는 분류 모델의 손실 함수로 교차 엔트로피를 쓰는 코드를 자동으로 만들어 줍니다. 그런데 왜 MSE 대신 교차 엔트로피를 쓰는지, 퍼플렉서티가 낮을수록 언어 모델이 더 좋다는 말이 무엇인지, 압축 파일이 왜 작아지는지 이해하려면 정보이론이 필요합니다.

정보이론은 정보를 감각적인 표현이 아니라 측정 가능한 양으로 다룹니다. 핵심 문장은 이것입니다. 정보는 메시지의 길이가 아니라 놀라움의 정도와 연결됩니다. 거의 확실한 사건은 정보량이 작고, 매우 드문 사건은 정보량이 큽니다.

엔트로피는 그 놀라움의 평균입니다. 분포가 고르게 퍼질수록 불확실성이 크고 엔트로피도 커집니다. 교차 엔트로피는 실제 분포를 잘못된 예측 분포로 코딩할 때 드는 평균 비용입니다.

정보량, 엔트로피, 교차 엔트로피, KL 발산을 하나의 흐름으로 정리합니다.

> **핵심 인사이트:** 분류 문제에 교차 엔트로피를 쓰는 이유는 예측 분포가 실제 분포와 멀수록 손실이 커지는 성질이 있기 때문입니다. 완벽한 예측(확률=1)이면 손실=0, 틀릴수록 손실이 기하급수적으로 커집니다.

## 이 글에서 다룰 문제

- 정보의 양은 무엇으로 측정할까요?
- 엔트로피는 왜 평균 정보량이라고 부를까요?
- 교차 엔트로피는 왜 분류 손실 함수로 자주 쓰일까요?
- KL 발산은 교차 엔트로피와 어떤 관계일까요?
- AI가 만든 분류 모델 코드에서 확인해야 할 것은 무엇인가요?

## 정보이론 핵심 패턴

```python
import math

# 정보량: 확률이 낮을수록 정보량이 큼
def info(p):
    return -math.log2(p)

# 엔트로피: 분포의 평균 정보량 (불확실성)
def entropy(probs):
    return sum(-p * math.log2(p) for p in probs if p > 0)

# 예시
print(entropy([0.5, 0.5]))      # 1.0 (최대 불확실성, 동전 던지기)
print(entropy([0.9, 0.1]))      # 0.469 (더 확실함)
print(entropy([1.0, 0.0]))      # 0.0 (완전 확실)
```

```python
# 교차 엔트로피: 실제 분포 p를 예측 분포 q로 코딩할 때 비용
def cross_entropy(p_true, q_pred):
    return sum(-p * math.log2(max(q, 1e-10))
               for p, q in zip(p_true, q_pred) if p > 0)

# KL 발산: 교차 엔트로피 - 엔트로피 (두 분포 간 차이)
def kl_divergence(p, q):
    return sum(pi * math.log2(max(pi, 1e-10) / max(qi, 1e-10))
               for pi, qi in zip(p, q) if pi > 0)

# 분류 모델 교차 엔트로피 손실
p_true = [0, 1, 0]       # 실제: 클래스 1
q_pred = [0.1, 0.7, 0.2] # 예측: 클래스 1에 70% 확률
print(f"CE Loss: {cross_entropy(p_true, q_pred):.3f}")  # 0.515
```

## 변경 전후 비교

**Before: 정보이론 없이 손실 함수 선택**
```text
- 분류 문제에 MSE를 사용 → 수렴이 느리고 성능이 낮음
- 손실값이 의미하는 바를 모름
- 퍼플렉서티가 낮으면 좋다는 말의 의미를 모름
- 왜 확률 출력에 log를 취하는지 이해 못함
```

**After: 정보이론 이해 후**
```text
- 분류 문제에 교차 엔트로피 → 확률 분포 학습에 적합
- 손실값이 "평균 몇 비트의 정보가 낭비되는가"로 해석됨
- 퍼플렉서티 = 2^엔트로피 = 선택지 수와 같은 감각
- log를 취하면 곱셈이 덧셈이 되어 수치 안정성 향상
```

## 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 방법 |
|------|-------------|-----------|
| 분류에 MSE 사용 | 확률 분포 학습에 부적합, 그래디언트 소실 | 교차 엔트로피 손실 사용 |
| log(0) 계산 | -무한대로 폭발 | `max(p, 1e-10)` 클리핑 또는 `epsilon` 추가 |
| 엔트로피와 교차 엔트로피 혼동 | 손실 해석 오류 | 엔트로피는 한 분포, 교차 엔트로피는 두 분포 |
| KL 발산의 비대칭성 무시 | D_KL(P‖Q) ≠ D_KL(Q‖P) | 용도에 맞는 방향으로 사용 |
| 소프트맥스 없이 교차 엔트로피 적용 | 확률 합이 1이 되지 않을 수 있음 | 출력에 소프트맥스 또는 시그모이드 적용 |

## 운영 체크리스트

- [ ] 분류 문제에 교차 엔트로피 손실을 사용한다
- [ ] log(0) 처리를 위한 클리핑 또는 epsilon이 있다
- [ ] 손실값을 "예측 분포와 실제 분포의 거리"로 해석할 수 있다
- [ ] 퍼플렉서티로 언어 모델 품질을 평가한다
- [ ] 클래스 불균형 시 가중 교차 엔트로피를 고려한다

## 처음 질문으로 돌아가기

- **정보량이란?** 어떤 사건의 정보량 = -log2(p)입니다. 확률이 낮을수록 정보량이 크고 놀라움이 큽니다. 단위는 비트(bit)입니다.
- **엔트로피란?** 분포의 평균 정보량입니다. 균등 분포일수록 엔트로피가 크고(최대 불확실성), 한 사건만 확실할수록 엔트로피가 0에 가깝습니다.
- **교차 엔트로피를 손실 함수로 쓰는 이유는?** 예측 분포가 실제 분포와 멀수록 손실이 커지고, 일치할수록 0에 가까워집니다. 이 성질이 모델이 올바른 확률을 학습하도록 유도합니다.

## 정리

바이브코딩에서 AI가 만들어 준 분류 모델 코드에서 손실 함수 선택(교차 엔트로피 여부), log(0) 처리, 소프트맥스 적용을 반드시 확인하세요. 정보이론은 압축, 통신, 머신러닝 손실 함수 뒤에 있는 공통 언어입니다. 다음 글에서는 알고리즘과 수학을 다룹니다.
