# Computer Science Major 101 (2/10): 1학년 과목 이해하기

1학년 시간표를 보면 전공다운 이름보다 수학과 기초 과목이 먼저 눈에 들어옵니다. 코딩을 배우러 왔다고 생각한 학생에게는 이 구성이 다소 멀게 느껴질 수 있습니다.

이 글은 Computer Science Major 101 시리즈의 2번째 글입니다.

![Computer Science Major 101 2장 흐름 개요](https://yeongseon-books.github.io/book-public-assets/assets/computer-science-major-101/02/02-01-first-year-foundation-map.ko.png)
*컴퓨터학과 전공 가이드 2장 흐름 개요*

> 1학년의 핵심은 나중에 화려한 주제를 버틸 수 있게 만드는 기반 공사에 있습니다.

## 이 글에서 다룰 문제

- 왜 1학년 과목은 수학과 프로그래밍 비중이 유난히 클까요?
- 미적분, 선형대수, 이산수학, 프로그래밍 입문은 각각 어떤 역할을 맡을까요?
- 지금은 진로와 멀어 보이는 과목이 왜 2학년 이후 성과를 가를까요?
- 첫 프로그래밍 언어를 고를 때 무엇을 기준으로 해야 할까요?
- 1학년에서 가장 자주 발생하는 학습 실패 패턴은 무엇일까요?

## 왜 1학년은 수학 중심인가

많은 학생이 컴퓨터학과에 입학하면서 "코딩을 배울 것"이라고 기대합니다. 그런데 1학기 시간표를 보면 미적분, 선형대수, 이산수학, 프로그래밍 입문이 나란히 있습니다. "이게 컴퓨터랑 무슨 상관이지?"라는 질문이 자연스럽게 나옵니다.

실제로 이 질문은 맞습니다. 직접적인 관련이 당장 보이지 않는 것이 정상입니다. 하지만 2~3학년이 되면 이 연결이 선명해집니다.

- 미적분은 머신러닝의 경사 하강법(gradient descent)에서 손실 함수를 최소화하는 직관을 줍니다.
- 선형대수는 딥러닝의 행렬 연산, 이미지 변환, 추천 시스템의 임베딩 유사도 계산에 직접 쓰입니다.
- 이산수학의 명제 논리는 알고리즘 정확성 증명과 조건문 경계 사례 설계에 연결됩니다.
- 프로그래밍 입문은 사실상 모든 후속 과목의 실습 기반입니다.

1학년 기초는 알고리즘, AI, 시스템처럼 뒤에 나오는 모든 과목의 바닥입니다. 이 시기에 쌓은 기초가 약하면 상위 과목에서 계속 같은 구멍을 다시 메우게 됩니다.

## 각 과목의 역할

- **미적분(calculus)**: 연속적으로 변하는 값을 다루는 수학입니다. 최적화, 변화율, 극값 개념이 ML 학습 과정의 직관적 토대가 됩니다.
- **선형대수(linear algebra)**: 벡터와 행렬을 중심으로 구조를 보는 수학입니다. 데이터를 고차원 공간에서 다루는 거의 모든 분야에 씁니다.
- **이산수학(discrete math)**: 논리와 집합, 그래프를 다루는 수학입니다. 알고리즘 분석과 증명의 언어를 제공합니다.
- **프로그래밍 입문(intro programming)**: 언어와 프로그램 기본기를 배우는 과목입니다. 함수 분해, 조건 설계, 반복 구조, 예외 처리를 손에 익히는 시간입니다.
- **실습(lab)**: 손으로 직접 구현해 보는 시간입니다. 강의 이해와 실행 능력은 별개입니다.

## 왜 여기서 막히는가: 흔한 시나리오

**시나리오 1 — "선형대수는 외워서 시험만 통과했다"**

재원은 1학년 때 선형대수를 행렬 계산 공식을 외워 통과했습니다. 2학년 컴퓨터그래픽스 과목에서 회전 행렬이 나왔을 때 갑자기 막혔습니다. 계산은 할 수 있는데 "왜 이 변환이 회전인지" 설명이 안 됐기 때문입니다. 3학년 머신러닝에서 역전파(backpropagation) 행렬 미분이 나왔을 때는 아예 포기하고 라이브러리만 쓰게 됐습니다.

발생 신호: 계산은 하지만 구조 설명이 안 됩니다. 다음 과목에서 같은 개념이 나올 때마다 처음부터 다시 찾아봐야 합니다.

해결 방향: 행렬 곱을 계산 절차가 아니라 선형 변환으로 설명하는 연습이 필요합니다. "이 행렬은 어떤 공간 변환인가"를 말로 설명할 수 있어야 합니다.

**시나리오 2 — "언어를 자꾸 바꿨더니 아무것도 깊게 모르게 됐다"**

예림은 처음 C를 배우다가 어렵다고 Python으로 갔고, Python 강의를 보다가 JavaScript 프론트엔드가 더 재미있을 것 같아 또 이동했습니다. 1학년이 끝날 때 세 언어를 "조금씩" 알지만 함수 분해, 재귀, 예외 처리를 하나의 언어에서 제대로 다루는 경험이 없었습니다. 자료구조 과목에서 연결 리스트를 직접 구현하는 과제에서 완전히 막혔습니다.

발생 신호: 문법은 여러 언어로 읽힌다고 느끼지만, 한 언어로 500줄 이상 짜 본 경험이 없습니다.

해결 방향: 첫 언어 하나로 함수 분해, 재귀, 파일 I/O, 예외 처리를 완성한 뒤 두 번째 언어로 이동해야 합니다.

**시나리오 3 — "수학은 이해했는데 코드로 연결이 안 된다"**

현우는 이산수학 강의에서 집합, 논리, 그래프를 잘 이해했습니다. 그런데 자료구조 과목에서 "BFS 탐색 결과를 집합 연산으로 설명하라"는 문제가 나왔을 때 두 과목이 연결된다는 생각 자체를 못 했습니다. 수학 과목과 코딩 과목을 완전히 별개로 공부했기 때문입니다.

## 첫 언어 선택: 무엇을 기준으로 할까

| 판단 항목 | Python 중심 시작 | C 중심 시작 | Java 중심 시작 |
| --- | --- | --- | --- |
| 초반 진입 장벽 | 낮음 | 중간~높음 | 중간 |
| 문법 대비 개념 학습 속도 | 빠름 | 중간 | 중간 |
| 메모리/저수준 감각 | 상대적으로 약함 | 강함 | 중간 |
| 자료구조 과목 연결 | 좋음 | 매우 좋음 | 좋음 |
| 웹·데이터 실습 연결 | 매우 좋음 | 보통 | 좋음 |
| 초심자 좌절 위험 | 낮음 | 높음 | 중간 |

중요한 점은 어느 언어가 절대적으로 우월하다는 결론이 아닙니다. 1학년에서 필요한 것은 한 언어로 함수 분해, 조건 설계, 예외 처리, 테스트 습관을 고정하는 일입니다. 언어를 자주 바꾸면 문법은 늘지만 사고 체계가 약해집니다.

## 수학 과목과 코딩 과목을 연결하는 학습법

많은 학생이 수학은 시험용, 코딩은 프로젝트용으로 분리해 생각합니다. 하지만 실제 전공 성과는 두 영역의 연결에서 결정됩니다.

- 이산수학의 명제 논리 → 조건문 경계 사례를 더 정확히 다루게 됩니다
- 선형대수의 벡터 감각 → 추천 점수 계산, 임베딩 유사도 해석에 직접 연결됩니다
- 미적분의 변화율 개념 → 최적화 과정에서 학습률과 손실 감소를 읽는 기본 직관이 됩니다

아래는 1학년 한 학기 운영에 바로 적용할 수 있는 최소 루프입니다.

- 강의 직후 24시간 안에 핵심 개념 3줄 요약
- 48시간 안에 관련 문제 3개 직접 풀이
- 일주일 안에 틀린 문제 원인 분류: 개념/계산/해석/주의력
- 다음 주 시작 전에 약점 1개만 명확히 보강

## 1학년 과목의 실습 코드 예시

```python
# 1단계 — 과목 나열과 상위 과목 연결
courses = ["calculus", "linalg", "discrete", "intro_prog"]

maps = {
    "calculus": ["ml", "optimization"],
    "linalg": ["ml", "graphics", "nlp"],
    "discrete": ["algorithms", "theory_of_computation"],
    "intro_prog": ["all_cs_courses"]
}

# 2단계 — 주당 학습 시간 배정
hours = {c: 6 for c in courses}

# 3단계 — 실습 비중 (프로그래밍은 별도 실습 필수)
labs = {"intro_prog": 4, "discrete": 1}

# 4단계 — 약점 표시 (주 5시간 미만이면 위험)
weak = [c for c, h in hours.items() if h < 5]
print("약한 과목:", weak)
```

각 과목이 어디로 이어지는지 적어 보면 목적이 분명해집니다. 특히 프로그래밍 입문은 사실상 모든 후속 과목의 공통 기반입니다.

## 이 과목이 실무에서 어떻게 쓰이는가

1학년 수학 과목이 실무와 직결되는 세 가지 사례입니다.

**미적분 → 최적화**: 딥러닝 모델 학습 시 Adam, SGD 같은 옵티마이저는 손실 함수의 기울기를 미분으로 계산합니다. 학습률 조정, 손실 곡선 해석 모두 미분 감각이 기반입니다.

**선형대수 → 데이터 처리**: 추천 시스템의 사용자-아이템 행렬, 이미지 처리의 컨볼루션, NLP의 단어 임베딩이 모두 행렬 연산입니다. NumPy 배열 브로드캐스팅도 선형대수 개념입니다.

**이산수학 → 알고리즘**: 알고리즘 분석에서 점화식을 세우고 풀 때 이산수학 능력이 필요합니다. 그래프 탐색, 정렬 알고리즘 정당성 증명도 마찬가지입니다.

## 1학년 말 점검표

학년이 끝날 때 아래 항목을 기준으로 스스로 점검하면 이후 과목의 난이도를 크게 줄일 수 있습니다.

- 함수, 반복, 자료형, 예외 처리의 차이를 말로 설명할 수 있는가.
- 시간 복잡도의 기본 개념을 문제 풀이에 적용할 수 있는가.
- 행렬 곱의 의미를 계산 절차가 아니라 구조 관점으로 설명할 수 있는가.
- 논리식의 참/거짓을 코드 분기와 연결해 설명할 수 있는가.
- 혼자 푼 문제와 협업으로 푼 문제의 차이를 기록해 두었는가.

이 다섯 개가 채워지면 2학년 전공의 진입 비용이 크게 낮아집니다.

## 1학년 학습 계획 템플릿

| 과목 | 주간 목표 | 검증 방식 | 보강 조건 |
| --- | --- | --- | --- |
| 미적분 | 핵심 정리 2개 + 문제 10개 | 오답 원인 3유형 분류 | 오답률 30% 초과 시 주말 90분 보강 |
| 선형대수 | 벡터/행렬 개념 요약 | 손계산 5문제 + 코드 1회 | 개념 설명 실패 시 노트 재작성 |
| 이산수학 | 명제/집합/증명 훈련 | 증명 문제 3개 구두 설명 | 논리 비약 발견 시 스터디 질문 등록 |
| 프로그래밍 | 함수/반복/예외 실습 | 테스트 통과 + 코드 리뷰 1회 | 테스트 실패 2회 이상 시 범위 축소 |

또한 일부 학과는 상대평가를 적용하므로 GPA 계산 규칙을 미리 이해해 두는 편이 유리합니다.

```text
예시 GPA = (A0 3학점×4.0 + B+ 3학점×3.5 + A+ 3학점×4.5 + B0 3학점×3.0) / 12
         = 45.0 / 12 = 3.75
```

학점 계산의 목적은 점수 집착이 아니라 위험 과목을 조기에 찾는 데 있습니다.

## 자주 하는 실수 5가지

1. **출석만 하고 복습하지 않는 일입니다.** 강의 24시간 내 요약이 없으면 기억 유지율이 급격히 낮아집니다.
2. **수학을 이해가 아니라 암기로만 버티는 일입니다.** 2학년에서 같은 개념이 더 복잡하게 나올 때 무너집니다.
3. **언어를 자꾸 바꾸면서 기초를 미루는 일입니다.** 한 언어에서 구조적 사고를 완성하는 것이 먼저입니다.
4. **실습 과제를 마감 직전에 시작하는 일입니다.** 구현은 이해와 별개의 능력이며 손에 익히는 시간이 필요합니다.
5. **질문하지 않고 혼자 오래 끌고 가는 일입니다.** 막힘 30분 이상이면 질문하는 편이 시간 대비 훨씬 효율적입니다.

  - 미적분은 최적화 직관, 선형대수는 다차원 구조 언어, 이산수학은 논리·증명 습관, 프로그래밍 입문은 실행 가능한 절차로 전환하는 능력을 줍니다.

- **지금은 진로와 멀어 보이는 과목이 왜 2학년 이후 성과를 가를까요?**
  - 1학년에 약했던 영역이 2~3학년 과목에서 갑자기 전제로 등장하기 때문입니다. 재원 시나리오처럼 선형대수를 외워 넘긴 학생은 머신러닝에서 정확히 그 지점에서 막힙니다.

- **첫 프로그래밍 언어를 고를 때 무엇을 기준으로 해야 할까요?**
  - 언어 자체보다 "이 언어로 함수 분해, 재귀, 예외 처리를 제대로 끝낼 수 있는가"가 기준입니다. 하나를 깊게 파는 것이 여러 개를 얕게 아는 것보다 훨씬 강한 기반이 됩니다.

- **1학년에서 가장 자주 발생하는 학습 실패 패턴은 무엇일까요?**
  - 수학과 프로그래밍을 분리해 공부하는 것입니다. 이산수학의 논리 개념을 조건문 설계와 연결하지 않으면 두 과목 모두 독립된 암기 과목으로 끝납니다.

## 정리

1학년 과목은 전공다운 재미를 늦추는 구간이 아니라, 이후 과목을 버티게 만드는 기초 체력 구간입니다. 미적분, 선형대수, 이산수학, 프로그래밍 입문을 하나의 준비 운동으로 이해하면 학습 방향이 훨씬 선명해집니다. 다음 글에서는 많은 학생이 전공의 중심으로 느끼는 자료구조와 알고리즘을 봅니다.
