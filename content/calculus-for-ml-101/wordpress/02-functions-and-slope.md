# 바이브코딩을 위한 ML 미적분 (2/10): 함수와 기울기

이 글은 바이브코딩을 위한 ML 미적분 시리즈의 2번째 글입니다.

ML에서 "손실 함수"라는 말을 자주 씁니다. 그런데 그 함수가 어떤 모양인지 떠올릴 수 있나요? AI에게 "이 모델의 loss가 수렴하지 않아요"라고 말할 때, AI는 "함수의 모양", "기울기의 크기", "평평한 구간"이라는 언어로 답합니다. 함수와 기울기를 이해하면 이 대화가 가능해집니다.

함수는 입력을 출력으로 변환하는 규칙입니다. ML에서 함수는 파라미터를 손실값으로 변환하며, 기울기는 그 함수가 현재 위치에서 얼마나 가파른지를 나타냅니다. 기울기가 가파르면 빠르게 학습하고, 기울기가 평평하면 학습이 느려집니다.

바이브코딩에서 AI에게 "이 활성화 함수에서 gradient vanishing이 왜 생겨?"라고 물을 수 있으면, "sigmoid의 기울기가 0과 1에서 0에 가까워지기 때문입니다"라는 답을 이해할 수 있습니다. 함수의 모양이 기울기를 결정하고, 기울기가 학습을 결정합니다.

> 함수의 기울기는 현재 위치에서 조금 움직였을 때 출력이 얼마나 변하는지를 나타냅니다. ML에서 이 기울기가 학습 속도와 방향을 결정합니다.

---

## 이 글에서 다룰 문제

- 선형 함수와 비선형 함수의 기울기는 어떻게 다를까요?
- ML에서 자주 쓰는 함수들(sigmoid, ReLU)의 기울기 특성은 무엇일까요?
- 기울기가 너무 크거나 작을 때 학습에 어떤 문제가 생길까요?
- 함수 모양을 보고 학습 동작을 예측할 수 있을까요?
- AI에게 gradient 문제를 어떻게 설명해야 할까요?

함수의 모양은 기울기 패턴을 결정하고, 기울기 패턴은 학습 동작을 결정합니다. 이 연결을 이해하면 AI에게 "왜 이 함수를 쓰면 gradient vanishing이 생겨?"라고 물을 수 있습니다.

## Before / After

**Before — 활성화 함수를 기울기 없이 선택:**

```python
# sigmoid를 기본값으로 사용
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(10, 5),
    nn.Sigmoid(),  # 깊은 네트워크에서 gradient vanishing 발생!
    nn.Linear(5, 1)
)
# 이유를 모르면 loss가 수렴 안 할 때 원인 파악 불가
```

**After — 기울기 특성을 이해하고 함수 선택:**

```python
# ReLU: 양수 구간에서 기울기 = 1, gradient vanishing 없음
model = nn.Sequential(
    nn.Linear(10, 5),
    nn.ReLU(),  # 기울기 특성 이해 후 선택
    nn.Linear(5, 1)
)
# AI에게 "왜 ReLU가 sigmoid보다 깊은 네트워크에 좋아?"라고 물을 수 있음
```

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|------|------------|------|
| 활성화 함수를 기본값으로만 사용 | gradient 문제 원인 모름 | 함수 기울기 특성 이해 후 선택 |
| loss 스케일 무시 | 기울기 크기 불균형 | 손실 함수 값의 범위 확인 |
| 함수 모양 시각화 없이 문제 파악 | 추상적 이해만으로 디버깅 한계 | matplotlib으로 함수와 기울기 그려보기 |
| 기울기 폭발/소실 개념 없이 학습률 조정 | 근본 원인 해결 안 됨 | gradient norm 모니터링 |
| 선형 함수만 이해하고 비선형 무시 | 복잡한 패턴 학습 불가 이유 모름 | 비선형 함수의 기울기 변화 특성 이해 |

## AI 협업 팁

함수와 기울기 관련 AI 질문 패턴:

1. **함수 기울기 설명 요청**: "sigmoid의 기울기가 어떻게 변해?"
2. **문제 진단 요청**: "이 부분에서 gradient vanishing이 생기는 이유는?"
3. **대안 제시 요청**: "sigmoid 대신 어떤 활성화 함수가 더 나을까?"

예시 프롬프트:
> "sigmoid와 ReLU의 기울기 특성 차이를 설명해줘. 깊은 네트워크에서 각각 어떤 문제가 생기고, 왜 ReLU를 더 많이 쓰는지 알고 싶어."

## 처음 질문으로 돌아가기

함수의 기울기를 이해하면 "왜 이 활성화 함수에서 학습이 안 되나요?"라는 질문을 "이 구간에서 기울기가 0에 가까워서 gradient vanishing이 생기는 건 아닌가요?"로 바꿀 수 있습니다. 이 언어로 AI와 대화하면 훨씬 정확한 답을 얻을 수 있습니다.

## 정리

함수의 모양이 기울기 패턴을 결정하고, 기울기 패턴이 ML 학습 동작을 결정합니다. 활성화 함수를 선택할 때 그 기울기 특성을 이해하면, 학습 문제를 AI와 함께 정확하게 진단하고 해결할 수 있습니다.
