# 바이브코딩을 위한 ML 미적분 (1/10): 미분이란 무엇인가

이 글은 바이브코딩을 위한 ML 미적분 시리즈의 1번째 글입니다.

"AI가 모델 학습을 다 해주는데 미적분을 왜 배워야 하나요?"라는 질문을 자주 받습니다. 맞습니다. PyTorch나 TensorFlow는 gradient를 자동으로 계산합니다. 그런데 훈련이 불안정하거나, loss가 줄지 않거나, gradient가 0에 가까워질 때 "왜 이런 일이 생겼나?"를 이해하려면 미분 감각이 필요합니다.

바이브코딩에서 AI에게 "학습률을 얼마로 설정해야 해?", "이 loss가 수렴하지 않는 이유가 뭐야?"라고 물을 때, AI는 gradient와 미분 언어로 답합니다. 그 언어를 모르면 AI의 답을 이해할 수 없습니다.

경사하강법은 손실을 줄이는 방향으로 이동하는 절차이고, 그 방향은 미분에서 나옵니다. 역전파는 거대한 합성함수의 미분을 효율적으로 계산하는 방법입니다. ML 학습 루프의 핵심 용어들은 거의 모두 미분 위에 서 있습니다. 이 시리즈는 ML 엔지니어가 학습 과정을 읽기 위해 꼭 필요한 최소한의 미분 직관을 만드는 데 목적이 있습니다.

> 미분은 함수 전체를 한 번에 설명하는 도구가 아니라, 지금 서 있는 지점에서 어느 방향으로 얼마나 움직여야 하는지 알려 주는 국소 신호입니다.

## 이 글에서 다룰 문제

- 머신러닝에서 말하는 학습은 왜 미분과 직접 연결될까요?
- 평균 변화율과 순간 변화율은 무엇이 다를까요?
- 접선의 기울기와 도함수는 어떻게 이해하면 실용적일까요?
- 미분 감각이 없을 때 ML 디버깅에서 어떤 문제가 생길까요?
- 바이브코딩에서 AI와 미분 관련 대화를 어떻게 할 수 있을까요?

미분을 모르면 모델은 돌아갑니다. 하지만 훈련이 불안정하거나 loss가 수렴하지 않을 때, 숫자를 해석할 언어가 없으면 원인을 찾을 수 없습니다. 미분 감각이 있으면 gradient 크기와 방향으로 현상을 읽을 수 있습니다.

## Before / After

**Before — 미분 감각 없이 AI에게 학습 문제 질문:**

```
Q: "loss가 줄지 않아요. 뭐가 문제인가요?"
A: "학습률을 바꿔보세요."
→ 왜 학습률이 문제인지, 어떻게 바꿔야 하는지 이해 못 함
```

**After — 미분 직관으로 AI와 구체적인 대화:**

```
Q: "gradient가 0에 가깝게 출력돼요. 이게 local minimum인가요 아니면
    saddle point인가요? 어떻게 구분해요?"
A: "Hessian 행렬의 고유값을 확인하면 구분할 수 있어요.
    saddle point라면 learning rate scheduler나 momentum을 써보세요."
→ 원인을 이해하고 해결책을 선택할 수 있음
```

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|------|------------|------|
| gradient를 추상적 숫자로만 봄 | 학습 문제 원인 파악 불가 | gradient를 "함수의 경사도"로 시각화 |
| 학습률을 감으로만 조정 | 발산이나 수렴 실패 반복 | gradient 크기에 맞게 학습률 설정 이해 |
| loss 곡선만 보고 미분 무시 | 피상적 디버깅 | gradient norm도 함께 모니터링 |
| 미분을 공식으로만 외움 | 새로운 손실 함수 이해 불가 | "이 점에서 얼마나 빠르게 변하는가" 직관 우선 |
| AutoDiff를 블랙박스로만 사용 | 수치적 불안정 문제 진단 불가 | numerical gradient와 비교하는 습관 |

## AI 협업 팁

미분 관련 AI 질문 패턴:

1. **gradient 해석 요청**: "이 gradient 값이 의미하는 게 뭐야?"
2. **학습 불안정 진단**: "gradient가 폭발하는 이유와 해결책은?"
3. **직관 요청**: "이 함수의 미분을 수학 없이 설명해줘"

예시 프롬프트:
> "f(x) = x² + 2x + 1의 x=3에서 미분값이 뭐야? 그게 ML 학습에서 어떤 의미야?"

## 운영 체크리스트

- [ ] 미분이 "순간 변화율"임을 이해하고 있는가?
- [ ] gradient가 ML에서 "손실 함수의 경사 방향"임을 설명할 수 있는가?
- [ ] 학습률이 gradient와 어떻게 연결되는지 이해하는가?
- [ ] AI가 gradient 관련 답변을 줬을 때 이해할 수 있는가?
- [ ] 수치 미분으로 gradient를 검증하는 방법을 알고 있는가?

## 처음 질문으로 돌아가기

ML에서 학습이 불안정할 때, 미분 감각이 있으면 "gradient가 너무 크거나 작기 때문"이라고 진단하고 AI에게 구체적인 해결책을 요청할 수 있습니다. 미분은 공식 암기가 아니라 AI와 ML 학습 과정에 대해 대화하는 언어입니다.

## 정리

미분은 함수가 한 점에서 얼마나 빠르게 변하는지를 측정하는 도구입니다. ML에서는 이 정보를 통해 파라미터를 어느 방향으로 얼마나 움직일지 결정합니다. 바이브코딩에서 미분 직관은 AI에게 학습 문제를 정확하게 설명하고 해결책을 이해하는 기반이 됩니다.

다음 글에서는 함수와 기울기를 다룹니다. 다양한 함수 모양이 ML에서 어떤 학습 동작으로 이어지는지 배웁니다.
