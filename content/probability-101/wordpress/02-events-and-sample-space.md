# 바이브코딩을 위한 확률 기초 (2/10): 사건과 표본공간

이 글은 **바이브코딩을 위한 확률 기초** 시리즈의 2편입니다. AI 모델이 출력하는 확률 점수를 제대로 읽으려면 확률의 바닥 문법부터 알아야 합니다.

---

AI 분류 모델을 써보면 출력이 이렇게 나옵니다: `[0.72, 0.18, 0.10]`. 세 숫자, 합이 1. 이게 왜 세 개인지, 왜 합이 1인지, 0.72가 어떤 결과에 대한 확률인지 — 이 질문들이 전부 "표본공간과 사건"을 알아야 풀립니다.

> "확률 문제의 절반은 표본공간을 올바르게 정의하는 순간 풀립니다. AI 모델 출력도 마찬가지입니다. 어떤 클래스들이 가능한지 먼저 정의해야 숫자에 의미가 생깁니다."

## 이 글에서 다룰 질문들

- 표본공간은 왜 확률 계산보다 먼저 나와야 할까요?
- 사건을 집합으로 쓰면 무엇이 쉬워질까요?
- 합사건, 곱사건, 여사건은 각각 어떤 집합 연산에 대응될까요?
- 상호배반과 독립은 왜 전혀 다른 개념일까요?
- 순서를 구분하느냐 마느냐가 왜 답을 바꿀까요?
- AI 모델에서 클래스 정의가 왜 이렇게 중요할까요?

---

## 바이브코딩 관점: 클래스 정의가 모든 것을 결정한다

AI로 이미지를 분류할 때 모델 출력은 이런 모습입니다.

### Before: 클래스 정의 없이 AI 결과 읽기

```python
# 이미지 분류 모델 출력
output = model.predict(image)
print(output)  # [0.72, 0.18, 0.10]

# 0.72가 뭔지? 어떤 세 가지 중 하나인지?
# 표본공간을 모르면 숫자는 의미가 없음
```

### After: 표본공간을 명시하고 읽기

```python
# 표본공간(가능한 클래스) 명시
sample_space = ["고양이", "개", "새"]  # 3개 클래스
output = model.predict(image)  # [0.72, 0.18, 0.10]

# 이제 의미가 있음
for cls, prob in zip(sample_space, output):
    print(f"P({cls}) = {prob:.2f}")

# P(고양이) = 0.72
# P(개) = 0.18
# P(새) = 0.10
print("합:", sum(output))  # 1.0 — 표본공간이 완전히 커버됨
```

이게 표본공간입니다. 가능한 결과 전체를 미리 정의해두지 않으면 확률 숫자가 무엇을 말하는지 알 수 없습니다.

## 집합 연산과 확률: 핵심 대응표

| 집합 연산 | 기호 | 확률 공식 | AI 활용 예시 |
| --- | --- | --- | --- |
| 합집합 | A ∪ B | P(A ∪ B) = P(A) + P(B) - P(A ∩ B) | "고양이 또는 개" 확률 |
| 교집합 | A ∩ B | P(A ∩ B) = P(A) × P(B) (독립 시) | 두 조건을 동시에 만족 |
| 여집합 | A^c | P(A^c) = 1 - P(A) | "다른 모든 클래스" 확률 |

```python
# AI 다중 레이블 분류에서 집합 연산
# 이미지에 여러 객체가 있을 수 있음

# 표본공간: 가능한 객체 집합
omega = {"고양이", "개", "새", "자동차", "나무"}

# 사건 정의
A = {"고양이", "개"}          # 동물류
B = {"개", "자동차"}          # 이동 관련?
not_A = omega - A             # 동물 아닌 것

# 집합 연산
union_AB = A | B              # A 또는 B
inter_AB = A & B              # A이면서 B (둘 다)

print(f"동물(A): {A}")
print(f"A ∪ B: {union_AB}")   # {'고양이', '개', '자동차'}
print(f"A ∩ B: {inter_AB}")   # {'개'}
print(f"A의 여집합: {not_A}") # {'새', '자동차', '나무'}
```

## 상호배반 vs 독립: 가장 헷갈리는 개념 쌍

AI 모델을 쓸 때 이 둘을 혼동하면 결과 해석이 완전히 어긋납니다.

| 속성 | 상호배반 | 독립 |
| --- | --- | --- |
| 정의 | A∩B = ∅ (동시 불가) | P(A∩B) = P(A)·P(B) |
| 의미 | 한 번에 하나만 가능 | 한쪽이 다른 쪽에 영향 없음 |
| AI 예시 | 단일 레이블 분류 클래스들 | 독립적인 두 분류 모델 결과 |

```python
# 단일 레이블 분류 = 상호배반 (동시에 고양이+개 불가)
classes_single = ["고양이", "개", "새"]
probs = [0.72, 0.18, 0.10]
# 이 세 확률은 상호배반 -> 합이 1

# 다중 레이블 분류 = 독립 가능 (동시에 "귀엽다"+"작다" 가능)
label_cute = 0.8   # P(귀엽다)
label_small = 0.6  # P(작다)
# 독립이라면: P(귀엽다 AND 작다) = 0.8 * 0.6 = 0.48
p_both = label_cute * label_small
print(f"P(귀엽고 작음): {p_both:.2f}")
```

**핵심:** softmax를 쓴 모델은 상호배반 클래스를 가정합니다. sigmoid를 쓴 모델은 각 레이블이 독립적일 수 있습니다.

## 포함-배제 원리: AI 다중 조건 분석에서 필수

여러 조건이 겹칠 때 사용자를 중복 없이 세는 문제는 포함-배제 원리가 필요합니다.

```python
# A/B 테스트에서 두 기능 사용자 계산
users_A = 1000    # 기능 A 사용자
users_B = 800     # 기능 B 사용자
users_AB = 300    # 두 기능 모두 사용자

# 포함-배제: A 또는 B 사용자
users_A_or_B = users_A + users_B - users_AB
print(f"A 또는 B 사용자: {users_A_or_B}명")  # 1500명

# 잘못된 계산 (중복 포함)
wrong = users_A + users_B
print(f"잘못된 계산: {wrong}명")  # 1800명 — 300명 중복!
```

## 자주 하는 실수

| 실수 | 설명 | 올바른 접근 |
| --- | --- | --- |
| 표본공간 없이 확률만 논하기 | "정확도 85%"가 어떤 전체 집합에서의 85%인지? | 항상 분모(전체)를 먼저 정의 |
| 상호배반과 독립 혼동 | "클래스가 겹치지 않으니 독립이다"는 오류 | 상호배반이면 오히려 강하게 종속 |
| 등확률 가정 남발 | 클래스 수 = 3이라고 각 1/3이 아님 | 데이터 불균형을 항상 확인 |
| 클래스 정의 불명확 | "비정상"의 기준이 팀마다 다름 | 사건 정의를 문서로 명시 |

## AI 팁: 모델 출력 구조 파악하기

```python
import numpy as np

def check_model_output_type(output):
    """모델 출력이 softmax인지 sigmoid인지 판별"""
    total = sum(output)

    if abs(total - 1.0) < 1e-6:
        print("Softmax 출력 (상호배반 클래스)")
        print(f"클래스 수: {len(output)}")
    elif all(0 <= p <= 1 for p in output):
        print("Sigmoid 출력 (독립 다중 레이블)")
        print(f"합: {total:.3f} (1이 아님)")
    else:
        print("원시 로짓(logit) 출력 — 확률 변환 필요")

# 예시
softmax_output = [0.72, 0.18, 0.10]
sigmoid_output = [0.8, 0.6, 0.3]

check_model_output_type(softmax_output)
print()
check_model_output_type(sigmoid_output)
```

## 처음 질문으로 돌아가기

- **표본공간은 왜 확률 계산보다 먼저 나와야 할까요?**
  가능한 모든 결과를 먼저 정해야 분모가 정해지고 확률을 정의할 수 있습니다. AI 모델도 클래스 목록이 없으면 softmax 출력이 의미를 가지지 못합니다.

- **상호배반과 독립은 왜 전혀 다른 개념일까요?**
  상호배반은 동시 발생이 불가능하다는 뜻(A∩B=∅)이고, 독립은 한쪽이 다른 쪽에 영향을 주지 않는다는 뜻입니다. 상호배반인 두 사건은 오히려 강하게 종속됩니다. softmax는 상호배반, sigmoid는 독립 가정으로 이어집니다.

- **AI 모델에서 클래스 정의가 왜 이렇게 중요할까요?**
  클래스가 곧 표본공간입니다. 어떤 가능한 결과들을 정의하느냐에 따라 각 확률의 의미가 완전히 달라집니다. 특히 "기타" 클래스를 포함하느냐, 멀티레이블을 허용하느냐에 따라 모델 설계가 근본적으로 달라집니다.

## 정리

표본공간과 사건은 확률의 문법입니다. AI 모델의 출력을 읽을 때도 "이 클래스들이 표본공간이고, 각 숫자는 해당 사건의 확률"이라는 구조를 먼저 파악해야 합니다. 다음 글에서는 조건부확률을 다룹니다. 새로운 정보를 알았을 때 확률이 어떻게 바뀌는지 — AI 모델의 예측이 맥락에 따라 달라지는 이유를 설명합니다.
