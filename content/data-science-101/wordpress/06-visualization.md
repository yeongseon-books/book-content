# 바이브코딩을 위한 데이터 사이언스 기초 (6/10): AI가 만든 차트가 오해를 부를 때

이 글은 바이브코딩을 위한 데이터 사이언스 기초 시리즈의 6번째 글입니다.

AI 코딩 도구로 차트를 만들면 빠르고 편리합니다. "이 데이터로 차트 만들어줘"라고 하면 즉시 여러 종류의 시각화가 나옵니다. 그런데 팀원이 AI가 만든 차트를 보고 완전히 다른 해석을 하는 경우가 생깁니다. 막대 차트의 Y축이 0이 아닌 값에서 시작해서 작은 차이가 엄청난 차이처럼 보이거나, 3D 파이 차트를 쓰는 바람에 조각 크기를 제대로 비교할 수 없거나, 이중 축 그래프 때문에 완전히 다른 스케일의 데이터가 연관된 것처럼 보이는 상황들입니다.

AI는 기술적으로 올바른 차트를 그립니다. 하지만 "어떤 메시지를 전달해야 하는가"는 AI가 자동으로 알 수 없습니다. 같은 데이터를 선 그래프로 보여주면 추세가 보이고, 막대 그래프로 보여주면 비교가 보이고, 파이 차트로 보여주면 비율이 보입니다. 어떤 메시지를 전달하고 싶은지 먼저 정하지 않으면 AI가 기본값으로 선택한 차트가 의도치 않게 오해를 만들 수 있습니다.

바이브코딩에서 시각화의 핵심은 "어떤 라이브러리를 쓰는가"보다 "어떤 메시지를 전달하는가"입니다. AI에게 차트를 요청할 때 "시각화해줘"만 요청하지 말고, "이 메시지를 전달하는 차트를 만들어줘"라고 요청하는 것이 좋습니다. 그리고 나온 결과물이 오해를 만들지 않는지 이 글의 체크리스트로 검토하면 됩니다.

좋은 차트는 예쁜 차트가 아닙니다. 5초 안에 핵심 메시지를 읽을 수 있고, 독자가 오해할 수 없는 차트입니다.

> 시각화는 분석의 마지막 한 줄입니다. AI가 그려줬더라도 오해 없이 읽히는지는 사람이 확인해야 합니다.

## 이 글에서 다룰 문제
- AI가 만든 차트가 왜 오해를 만들 수 있을까요?
- 메시지에 맞는 차트를 어떻게 선택해야 할까요?
- 막대 차트의 Y축, 이중 축, 3D 차트가 왜 위험할까요?
- AI에게 차트를 요청할 때 어떤 지시를 추가해야 할까요?
- 차트를 공유하기 전에 확인해야 할 것은 무엇인가요?

## 메시지에 따른 차트 선택 가이드

| 전달하고 싶은 메시지 | 좋은 차트 | 피해야 할 차트 | 이유 |
|---|---|---|---|
| 항목 간 비교 | 수평/수직 막대 차트 | 3D 파이 차트 | 길이 비교가 정확함 |
| 시간에 따른 추세 | 선 차트 | 3D 막대 차트 | 변화 방향/속도 파악 용이 |
| 분포 확인 | 히스토그램, 박스플롯 | 평균만 표시 | 꼬리/이상치 확인 가능 |
| 두 변수 관계 | 산점도 | 선 차트 | 변수 간 패턴 식별 |
| 구성 비율 | 100% 누적 막대 | 파이 차트(조각 6개 이상) | 카테고리 비교 용이 |

## AI에게 차트를 더 잘 요청하는 방법

```python
# 막연한 요청 (좋지 않음)
"""
채널별 매출을 시각화해줘
"""

# 메시지를 명시한 요청 (좋음)
"""
채널별 매출을 비교하는 수평 막대 차트를 만들어줘.
다음 조건을 지켜줘:
- Y축(매출)은 반드시 0에서 시작
- 단위(원)를 축 라벨에 명시
- 분석 기간(2026년 5월)을 제목에 포함
- colorblind-safe 팔레트 사용
- 각 막대 끝에 실제 수치 표시
"""

import pandas as pd
import matplotlib.pyplot as plt

sales = pd.read_csv("sales.csv", parse_dates=["date"])
channel = sales.groupby("channel", as_index=False)["revenue"].sum().sort_values("revenue")

fig, ax = plt.subplots(figsize=(8, 4))
ax.barh(channel["channel"], channel["revenue"])
ax.set_xlabel("매출 (원)")
ax.set_title("채널별 매출 비교 — 2026년 5월")
ax.set_xlim(0, None)  # Y축을 0에서 시작

# 각 막대에 수치 표시
for i, v in enumerate(channel["revenue"]):
    ax.text(v, i, f" {v:,.0f}", va="center")

plt.tight_layout()
plt.show()
```

## AI가 만든 차트에서 자주 발견되는 오해 패턴

**패턴 1: Y축이 0에서 시작하지 않음**
AI가 기본 설정으로 만든 막대 차트에서 Y축이 95에서 시작하면, 99와 97의 차이가 엄청난 것처럼 보입니다. AI에게 요청할 때 "Y축은 반드시 0에서 시작해줘"를 추가하면 됩니다.

**패턴 2: 이중 축 남용**
서로 다른 스케일의 두 데이터를 이중 축으로 표시하면 아무 관계 없는 데이터가 연관된 것처럼 보입니다. 대부분의 경우 별도 차트 두 개로 만드는 게 낫습니다.

**패턴 3: 3D 차트**
3D 파이 차트나 3D 막대 차트는 원근감 때문에 크기 비교가 정확하지 않습니다. "3D 효과 없이 2D로 만들어줘"라고 요청하면 됩니다.

## Before / After

**Before**: AI에게 "매출 트렌드 보여줘"라고 했더니 Y축이 95에서 시작하는 막대 차트가 나왔습니다. 팀에 공유했더니 "매출이 엄청 들쭉날쭉하네요"라는 반응이 왔는데, 실제로는 1-2% 변동에 불과했습니다.

**After**: AI에게 "Y축 0에서 시작하는 월별 매출 선 차트를 만들어줘. 주요 이벤트 날짜를 세로선으로 표시해줘"라고 요청했습니다. 팀이 추세와 이벤트 영향을 즉시 파악할 수 있었습니다.

## 바이브코딩할 때 자주 하는 실수
| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| "시각화해줘"만 요청 | AI가 임의로 차트 선택 | 전달할 메시지와 차트 종류 명시 |
| Y축이 0에서 시작 안 함 | 차이를 과장하는 차트 | "Y축은 0에서 시작" 조건 추가 |
| 3D 차트 사용 | 크기 비교 부정확 | "2D로 만들어줘" 명시 |
| 라벨/단위 없는 차트 공유 | 다음 주에 아무도 이해 못 함 | 축 라벨, 단위, 분석 기간 항상 포함 |

## AI에게 데이터 분석 요청하는 팁

차트를 AI에게 요청할 때 이 체크리스트를 프롬프트에 포함하면 오해를 줄일 수 있습니다:

1. **전달할 메시지**: "채널별 매출을 비교하기 위해"
2. **차트 종류**: "수평 막대 차트로"
3. **축 설정**: "Y축은 0에서 시작"
4. **라벨**: "단위(원)와 분석 기간을 제목에 포함"
5. **접근성**: "colorblind-safe 팔레트 사용"
6. **행동 제안**: "차트 아래에 캡션으로 핵심 인사이트와 권장 행동 한 줄 추가"

## 운영 체크리스트
- [ ] AI가 만든 차트의 Y축이 0에서 시작하는지 확인합니다
- [ ] 3D 차트나 이중 축이 없는지 확인합니다
- [ ] 축 라벨, 단위, 분석 기간이 모두 표시됩니다
- [ ] 5초 안에 핵심 메시지를 읽을 수 있는지 확인합니다
- [ ] 차트에 "그래서 무엇을 할지" 캡션이 있습니다
- [ ] colorblind-safe 팔레트를 사용합니다

## 처음 질문으로 돌아가기

"AI가 차트를 잘 만들어줬는데 왜 팀이 다른 해석을 할까요?"

AI는 기술적으로 올바른 차트를 만들지만, 전달하려는 메시지에 맞는 차트인지는 사람이 확인해야 합니다. Y축 시작점, 차트 종류, 축 라벨 같은 디자인 결정이 해석을 크게 바꿉니다. AI에게 메시지를 명시하고 오해 방지 조건을 함께 요청하면 훨씬 신뢰할 수 있는 차트를 얻을 수 있습니다.

## 정리

AI가 만든 차트가 오해를 부르는 것은 AI의 잘못이 아닙니다. 어떤 메시지를 전달해야 하는지 명시하지 않았기 때문입니다. 메시지 먼저, 차트 나중. AI에게 차트를 요청할 때 전달할 메시지, 차트 종류, 축 설정, 라벨을 함께 명시하면 오해 없는 시각화를 만들 수 있습니다. 다음 글에서는 AI가 모델을 골라줬을 때 그 선택이 맞는지 검토하는 방법을 다룹니다.
