# 바이브코딩을 위한 AI 이미지 생성 기초 (1/10): 첫 이미지 생성하기

> "AI야, 우리 앱에 쓸 히어로 이미지 만들어줘."
>
> 이 한 마디가 바이브코딩에서 이미지 작업의 시작입니다.

바이브코딩(Vibe Coding)에서 AI와 함께 프로덕트를 만들다 보면 이미지가 필요한 순간이 반드시 옵니다. 앱의 히어로 섹션, 블로그 썸네일, 프레젠테이션 슬라이드, SNS 포스트... 디자이너 없이 AI로 만들 수 있다면 개발 속도가 몇 배 빨라집니다.

문제는 "AI야 이미지 만들어줘"처럼 대충 요청하면 대충 나온다는 것입니다. 바이브코딩에서 코드를 AI에게 맡길 때 명확한 요구사항을 주는 것처럼, 이미지도 명확한 프롬프트가 필요합니다.

이 글은 AI 이미지 생성 기초 시리즈의 첫 번째입니다. 바이브코딩 흐름 안에서 AI 이미지를 어떻게 효율적으로 생성하는지를 기초부터 다룹니다.

---

## 이 글에서 다루는 5가지 질문

1. ChatGPT로 이미지를 생성하는 가장 빠른 방법은?
2. "a cat"과 상세한 프롬프트의 결과 차이는 얼마나 될까?
3. 바이브코딩 프로젝트에서 이미지가 필요한 순간은 언제인가?
4. 프롬프트의 5가지 핵심 요소는 무엇인가?
5. 결과가 마음에 안 들면 어떻게 수정하는가?

---

## 바이브코딩과 AI 이미지의 관계

바이브코딩은 AI와 대화하면서 코드를 작성하는 방식입니다. 같은 원리로 AI와 대화하면서 이미지를 만들 수 있습니다. 차이는 프롬프트의 형식입니다:

| 작업 | 프롬프트 형식 | 결과물 |
|------|------------|--------|
| 바이브코딩 | "로그인 폼 컴포넌트 만들어줘" | 코드 |
| AI 이미지 | "로그인 화면 UI 스크린샷처럼 보이는 이미지" | 이미지 |

바이브코딩 프로젝트에서 이미지가 필요한 순간들:
- 랜딩 페이지의 히어로 이미지
- 기능 소개 섹션의 일러스트
- 앱 아이콘 컨셉 이미지
- 팀/회사 소개용 이미지
- 블로그 포스트 헤더 이미지

## Before / After: 프롬프트 차이가 만드는 결과

### Before: 모호한 프롬프트

> a cat

### After: 구체적인 프롬프트

| 비교 | Before | After |
|------|--------|-------|
| 색상 | AI 임의 결정 | 오렌지색 지정 |
| 배경 | AI 임의 결정 | 창가, 골든아워 |
| 스타일 | AI 임의 결정 | 사진 느낌 |
| 결과 예측 가능성 | 낮음 | 높음 |

## 프롬프트의 5가지 핵심 요소

바이브코딩에서 컴포넌트의 props를 지정하듯, 이미지 프롬프트에도 핵심 "속성"들이 있습니다.

| 요소 | 설명 | 예시 |
|------|------|------|
| **주제** (Subject) | 무엇을 그릴지 | 오렌지색 털 고양이 |
| **스타일** (Style) | 어떤 분위기로 | 사진처럼, 수채화처럼 |
| **구도** (Composition) | 어떤 각도에서 | 클로즈업, 위에서 내려다보는 시점 |
| **조명** (Lighting) | 빛이 어떻게 | 따뜻한 오후 햇살, 네온 조명 |
| **배경** (Background) | 주제 뒤에 | 아늘한 거실, 도심 야경 |

```
// 이미지 프롬프트를 코드처럼 생각하면:
generateImage({
  subject: "orange tabby cat",
  style: "photorealistic",
  composition: "close-up",
  lighting: "golden hour",
  background: "window cozy room"
})
```

## 자주 하는 실수

바이브코딩에서 이미지를 처음 생성할 때 자주 빠지는 함정들입니다.

| 실수 | 예시 | 문제 | 해결책 |
|------|------|------|--------|
| 추상적 형용사 | "beautiful amazing image" | AI에게 정보 없음 | 명사/동사로 구체적 표현 |
| 스타일 미지정 | 스타일 키워드 없음 | 일관성 없는 결과 | photorealistic 등 지정 |
| 첫 결과에 포기 | 한 번 실패 후 중단 | 프롬프트 개선 기회 놓침 | 3번 이상 수정 시도 |
| 영어/한국어 혼용 | 두 언어 섞어서 | 일관성 저하 | 영어로 통일 권장 |

## AI 팁: 바이브코딩 흐름에서 이미지 생성

바이브코딩 중에 이미지가 필요하면 아래 흐름을 따르세요:

1. **목적 명확화**: "이 이미지가 어디에 쓰이는가?" (히어로 섹션? 아이콘? 썸네일?)
2. **스타일 결정**: 프로젝트 디자인 시스템에 맞는 스타일
3. **프롬프트 작성**: 5가지 요소 적용
4. **생성 + 평가**: 결과 보고 어떤 요소가 부족한지 파악
5. **반복 개선**: 요소 하나씩 수정

이 흐름은 바이브코딩에서 코드를 개선하는 흐름과 동일합니다.

## 정리

- 바이브코딩에서 이미지 생성은 코드 생성과 같은 원리로 작동한다
- 모호한 프롬프트는 모호한 결과를 만든다
- 주제, 스타일, 구도, 조명, 배경의 5가지 요소가 핵심이다
- 첫 결과에 만족하지 못해도 수정하면서 개선할 수 있다
