# 바이브코딩을 위한 통계 기초 (8/10): AI가 상관을 인과로 읽을 때 — 상관과 회귀

이 글은 바이브코딩을 위한 통계 기초 시리즈의 8번째 글입니다.

광고비와 매출 데이터를 AI에게 분석해달라고 했더니 이렇게 답했습니다. "상관계수 0.82로 강한 양의 상관관계가 있습니다. 광고비를 늘리면 매출이 높아질 것입니다." 이 설명은 논리적으로 그럴듯하지만 통계적으로 틀렸습니다. 상관관계는 인과관계를 증명하지 않습니다.

광고비와 매출이 함께 오르는 것은 두 변수가 모두 계절 요인의 영향을 받기 때문일 수 있습니다. 연말에 마케팅 예산을 늘리는 동시에 소비자 구매가 늘어나는 것처럼 제3의 변수(교란 변수)가 두 변수를 함께 움직이게 할 수 있습니다. AI는 이 가능성을 자동으로 확인하지 않습니다.

바이브코딩에서 AI는 상관계수를 빠르게 계산하고 회귀 모델을 만들어줍니다. 하지만 그 숫자가 인과를 의미하는지, 교란 변수가 있는지, 잔차가 패턴을 보이는지는 사람이 판단해야 합니다.

> 두 변수가 함께 움직인다는 것이 한 변수가 다른 변수를 일으킨다는 뜻은 아닙니다.

## 이 글에서 다룰 문제
- AI가 상관계수를 인과관계로 설명할 때 어떻게 바로잡을 수 있을까요?
- 상관계수는 무엇을 말하고 무엇은 말하지 못할까요?
- 회귀 분석에서 R²가 높아도 안심할 수 없는 이유는 무엇일까요?
- 잔차 분석은 AI 모델의 어떤 문제를 드러낼까요?
- AI에게 상관과 인과를 구분하도록 어떻게 요청해야 할까요?

## 상관과 회귀의 바이브코더 관점

AI에게 두 변수의 관계를 분석해달라고 할 때 이 구분을 명시하지 않으면 혼동이 생깁니다.

| 분석 | 무엇을 말하는가 | 무엇을 말하지 못하는가 |
|---|---|---|
| 상관계수 | 방향(양/음)과 강도 | 인과관계, 교란 변수 존재 여부 |
| 회귀 분석 | x 변화 시 y의 예측값 변화 | x가 y의 원인인지 여부 |
| R² | 모델이 데이터를 설명하는 비율 | 모델이 실제 현실을 설명하는지 |
| 잔차 분석 | 모델이 놓친 패턴 | 누락된 변수가 무엇인지 |

AI에게 "상관계수를 계산하되, 이것이 인과관계를 의미하지 않는다는 점을 명시하고, 교란 변수 가능성도 언급해줘"라고 요청하면 해석 오류를 줄일 수 있습니다.

## 상관계수 계산과 해석

```python
import numpy as np
import pandas as pd
from scipy import stats

# 광고비와 매출 데이터 (교란 변수: 계절성)
np.random.seed(42)
months = np.arange(1, 25)
seasonality = np.sin(2 * np.pi * months / 12) * 50  # 계절 요인

# 광고비와 매출 모두 계절 요인의 영향을 받음
ad_spend = 100 + seasonality + np.random.normal(0, 10, 24)
revenue = 500 + seasonality * 5 + np.random.normal(0, 30, 24)

corr, p_value = stats.pearsonr(ad_spend, revenue)
print(f"상관계수: {corr:.3f}")
print(f"p-value: {p_value:.4f}")
print()
print("주의: 높은 상관계수는 인과관계가 아닐 수 있습니다")
print("두 변수 모두 계절 요인(교란 변수)의 영향을 받고 있습니다")
```

상관계수가 높더라도 교란 변수가 있을 수 있습니다. AI에게 "이 상관관계의 교란 변수 가능성을 점검해줘"라고 요청하는 습관이 필요합니다.

## 회귀 분석과 잔차 확인

```python
from sklearn.linear_model import LinearRegression
import numpy as np

np.random.seed(42)
x = np.linspace(1, 10, 100)
y = 3 * x + 5 + np.random.normal(0, 2, 100)

X = x.reshape(-1, 1)
model = LinearRegression().fit(X, y)
y_pred = model.predict(X)
residuals = y - y_pred

print(f"회귀 계수: {model.coef_[0]:.3f}")
print(f"절편: {model.intercept_:.3f}")
print(f"R²: {model.score(X, y):.3f}")
print(f"잔차 평균: {residuals.mean():.4f}")
print(f"잔차 표준편차: {residuals.std():.3f}")

# 잔차에 패턴이 있는지 확인
correlation_with_x = np.corrcoef(x, residuals)[0, 1]
print(f"잔차-x 상관: {correlation_with_x:.3f}")
print("잔차-x 상관이 낮으면 선형 가정이 적절함")
```

잔차에 패턴이 남아 있으면 모델이 데이터의 중요한 구조를 놓쳤다는 신호입니다. AI에게 "회귀 분석 후 잔차 플롯도 그려줘. 잔차에 패턴이 있는지 확인해줘"라고 요청하는 것이 좋습니다.

## Before / After

**Before**: AI에게 광고비와 매출 데이터를 넘기며 "관계를 분석해줘"라고 합니다. AI가 "상관계수 0.82, 강한 양의 상관. 광고비 증가가 매출 증가를 이끕니다"라고 답합니다. 그 결과를 근거로 광고 예산을 크게 늘렸는데 매출 상승이 없었습니다.

**After**: AI에게 "광고비와 매출의 상관계수를 계산하되, 인과관계가 아님을 명시해줘. 교란 변수(계절성, 캠페인 외 요인) 가능성을 점검하고, 회귀 분석 후 잔차 플롯도 그려줘"라고 요청합니다. AI가 "계절성이 교란 변수로 작용하고 있으며, 계절 효과를 제거한 뒤 분석이 필요합니다"라고 답합니다.

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| 상관계수를 인과관계로 해석 | 교란 변수로 인해 실제 인과가 없을 수 있음 | AI에게 인과관계 아님을 명시 요청 |
| R²가 높으면 좋은 모델이라고 단정 | 과적합이거나 교란 변수 포함 가능 | 잔차 분석과 교차 검증도 함께 요청 |
| 잔차 분석 없이 회귀 결과 신뢰 | 모델이 놓친 패턴이 숨어 있을 수 있음 | 잔차 플롯 시각화 항상 요청 |
| 선형 관계 가정 없이 회귀 적용 | 비선형 관계에 선형 모델 적용 시 왜곡 | 산점도 먼저 확인 후 모델 선택 |

## AI에게 통계 관련 질문하는 팁

상관과 회귀 분석을 AI에게 요청할 때 인과 혼동을 막는 프롬프트 구조입니다:

1. **인과 구분 명시**: "상관관계를 분석하되, 인과관계를 의미하지 않는다는 점을 결과에 포함해줘"
2. **교란 변수 점검**: "이 두 변수에 영향을 줄 수 있는 교란 변수의 가능성을 언급해줘"
3. **잔차 분석 요청**: "회귀 분석 후 잔차 플롯을 그리고 패턴이 있는지 확인해줘"
4. **R² 해석 주의**: "R²가 높더라도 모델의 한계를 설명해줘"
5. **의사결정 범위 제한**: "이 분석으로 인과관계를 주장할 수 있는지 판단해줘"

## 운영 체크리스트
- [ ] AI가 상관을 인과로 설명할 때 바로잡을 수 있습니다
- [ ] 회귀 분석 후 잔차 플롯을 항상 확인합니다
- [ ] R²만으로 모델 품질을 판단하지 않습니다
- [ ] 교란 변수 가능성을 AI에게 명시적으로 점검 요청합니다
- [ ] 인과관계를 주장하려면 실험 설계가 필요함을 이해합니다

## 처음 질문으로 돌아가기

"AI가 상관계수를 인과관계로 설명할 때 어떻게 바로잡을 수 있나요?"

AI에게 "상관관계를 계산하되, 인과관계가 아니라는 점을 결과에 명시하고, 교란 변수 가능성도 언급해줘"라고 요청합니다. AI가 인과관계처럼 설명하면 "이건 상관관계야. 인과관계를 증명하려면 어떤 추가 분석이 필요해?"라고 다시 물어보는 것이 좋습니다.

## 정리

AI는 상관계수와 회귀 계수를 정확하게 계산하지만, 그것이 인과관계를 의미하는지는 사람이 판단해야 합니다. "인과관계가 아님을 명시해줘", "교란 변수 가능성을 점검해줘", "잔차 플롯을 그려줘"라는 세 가지 요청이 AI 회귀 분석의 신뢰도를 크게 높입니다. 다음 글에서는 AI가 p-value를 오해하지 않도록 다루는 법을 정리합니다.
