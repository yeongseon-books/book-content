# 바이브코딩을 위한 통계 기초 (7/10): AI에게 A/B 테스트 맡기기 전에 알아야 할 가설검정

이 글은 바이브코딩을 위한 통계 기초 시리즈의 7번째 글입니다.

새 버튼 색상이 전환율을 높이는지 확인하기 위해 A/B 테스트를 했습니다. AI에게 결과를 분석해달라고 했더니 "p-value가 0.04로 0.05 미만이므로 B 버전이 통계적으로 유의하게 더 낫습니다. 배포를 권장합니다"라는 답이 나왔습니다. 그 결과를 믿고 B 버전을 배포했는데, 실제 전체 트래픽에서는 전환율 차이가 거의 없었습니다.

무엇이 잘못되었을까요? AI가 p-value를 계산하는 것은 정확했습니다. 하지만 표본 크기가 충분했는지, 검정력이 적절했는지, 효과 크기가 실무적으로 의미 있는 수준인지는 확인하지 않았습니다. p < 0.05라는 기준 하나만으로 의사결정을 했기 때문에 발생한 문제입니다.

바이브코딩에서 AI는 가설검정의 계산은 빠르게 해줍니다. 하지만 검정 전에 가설을 미리 정했는지, 표본 크기가 충분한지, p-value와 효과 크기를 함께 봤는지는 사람이 확인해야 합니다.

> 가설검정의 목표는 p-value를 찾는 것이 아니라, 증거의 강도로 판단을 명확하게 하는 것입니다.

---

## 이 글에서 다룰 문제
- A/B 테스트를 AI에게 맡기기 전에 어떤 준비가 필요할까요?
- 귀무가설과 대립가설은 왜 데이터를 보기 전에 정해야 할까요?
- p < 0.05만으로 배포를 결정하면 어떤 문제가 생길까요?
- 1종 오류와 2종 오류는 실무에서 어떻게 다뤄야 할까요?
- 검정력과 표본 크기는 어떻게 사전에 계산할 수 있을까요?

## 가설검정의 바이브코더 관점

AI에게 A/B 테스트를 맡길 때 이 네 가지 요소를 미리 정해두지 않으면 결과를 신뢰할 수 없습니다.

| 요소 | 설명 | 바이브코딩에서 주의사항 |
|---|---|---|
| 귀무가설 H0 | "두 버전에 차이가 없다" | 데이터 보기 전에 정해야 함 |
| 대립가설 H1 | "B 버전이 A보다 전환율이 높다" | 방향(단측/양측) 미리 결정 |
| 유의수준 α | 허용할 거짓 경보 확률 (보통 0.05) | 실험 전 고정 |
| 검정력 | 실제 효과가 있을 때 잡아낼 확률 | 표본 크기 결정에 사용 |

AI에게 "먼저 표본 크기 계산을 해줘. 기대 효과 크기를 알려주면 필요한 표본 수를 계산해줘. 그 다음 데이터를 모아서 검정하자"라는 순서로 요청하면 검정 절차가 안전해집니다.

## 가설검정 실전 흐름

```python
import numpy as np
from scipy import stats

# 사전 준비: 표본 크기 계산
from statsmodels.stats.power import NormalIndPower

# 기대 효과 크기: 전환율 10% → 12.5% (절대 2.5%p 향상)
effect_size = 0.025 / np.sqrt(0.10 * 0.90)  # Cohen's h 근사
analysis = NormalIndPower()
required_n = analysis.solve_power(effect_size=effect_size,
                                   alpha=0.05, power=0.80,
                                   alternative='larger')
print(f"필요한 표본 크기 (각 그룹): {int(required_n)}")

# 실험 후: 검정 실행
np.random.seed(42)
n = int(required_n)
control = np.random.binomial(1, 0.10, n)
treatment = np.random.binomial(1, 0.125, n)

t_stat, p_value = stats.ttest_ind(control, treatment, alternative='less')
effect = treatment.mean() - control.mean()

print(f"\n=== 검정 결과 ===")
print(f"A 전환율: {control.mean():.3f}")
print(f"B 전환율: {treatment.mean():.3f}")
print(f"효과 크기 (절대): {effect:.3f} ({effect*100:.1f}%p)")
print(f"p-value: {p_value:.4f}")
print(f"결론: {'B 버전 배포 권장' if p_value < 0.05 and effect > 0 else '추가 데이터 필요'}")
```

검정 전 표본 크기를 계산하는 것이 핵심입니다. 표본이 부족한 상태에서 p-value를 보면 실제 효과가 있어도 잡아내지 못하는 2종 오류가 발생합니다.

## 1종 오류와 2종 오류

| 오류 유형 | 상황 | 바이브코딩 리스크 |
|---|---|---|
| 1종 오류 (False Positive) | 효과 없는데 있다고 판단 | 효과 없는 B 버전을 배포 |
| 2종 오류 (False Negative) | 효과 있는데 없다고 판단 | 좋은 B 버전을 폐기 |

p-value 기준만 맞추면 1종 오류를 줄일 수 있지만, 표본이 작으면 2종 오류가 커집니다. AI에게 "1종 오류와 2종 오류를 모두 고려해서 표본 크기를 계산해줘"라고 요청하면 두 가지 리스크를 균형 있게 다룰 수 있습니다.

## Before / After

**Before**: AI에게 A/B 테스트 결과를 바로 넘기며 "유의한 차이가 있는지 확인해줘"라고 합니다. AI가 "p=0.04, 유의함. B 버전 배포 권장"이라고 답합니다. 표본 크기 100명으로 진행한 테스트입니다. 배포 후 실제 차이가 없음을 확인합니다.

**After**: 실험 전에 AI에게 "전환율 10%에서 13%로 향상을 감지하려면 유의수준 0.05, 검정력 0.80 기준으로 표본이 몇 명 필요한지 계산해줘"라고 먼저 요청합니다. AI가 "각 그룹 약 680명"이라고 알려줍니다. 그 표본을 모은 뒤 검정합니다.

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| 데이터 보고 가설 세우기 | 데이터에 맞춰 가설을 바꾸면 p-value 무의미 | 데이터 수집 전 가설 고정 |
| p < 0.05만으로 배포 결정 | 효과 크기가 미미해도 유의하게 나올 수 있음 | 효과 크기와 p-value 함께 확인 |
| 표본 크기 계산 없이 실험 시작 | 검정력 부족으로 2종 오류 발생 | 사전에 표본 크기 계산 |
| 여러 번 검정하며 유리한 결과 선택 | p-hacking으로 1종 오류 증가 | 검정 횟수 제한, 다중검정 보정 |

## AI에게 통계 관련 질문하는 팁

A/B 테스트를 AI에게 맡길 때 이 순서로 요청하면 검정의 신뢰도가 높아집니다:

1. **실험 전 표본 계산**: "효과 크기 X%, 유의수준 0.05, 검정력 0.80 기준 필요 표본 수를 계산해줘"
2. **가설 명시**: "귀무가설은 '두 버전에 차이 없음', 대립가설은 'B 버전이 더 높음'으로 설정해줘"
3. **검정 후 효과 크기도 확인**: "p-value와 함께 효과 크기(절대값과 상대값)를 보고해줘"
4. **오류 유형 점검**: "1종 오류와 2종 오류 관점에서 이 결과를 해석해줘"
5. **의사결정 문장으로 마무리**: "이 결과를 근거로 배포 여부를 권장해줘"

## 운영 체크리스트
- [ ] 실험 전 귀무가설과 대립가설을 데이터 없이 정합니다
- [ ] 필요 표본 크기를 사전에 계산합니다
- [ ] p-value와 효과 크기를 함께 확인합니다
- [ ] 1종 오류(거짓 경보)와 2종 오류(놓침) 리스크를 모두 고려합니다
- [ ] 중간에 여러 번 검정하지 않고 미리 정한 표본에 도달 후 검정합니다
- [ ] AI 결과에 효과 크기가 포함되어 있는지 확인합니다

## 처음 질문으로 돌아가기

"A/B 테스트를 AI에게 맡기기 전에 어떤 준비가 필요한가요?"

데이터를 보기 전에 귀무가설, 대립가설, 유의수준을 정해야 합니다. 그리고 기대하는 효과 크기와 검정력을 고려해 필요한 표본 크기를 미리 계산해야 합니다. 이 준비 없이 AI에게 데이터를 넘기면 p < 0.05라는 숫자가 나와도 그 의미를 신뢰할 수 없습니다.

## 정리

가설검정은 AI가 빠르게 계산해주지만, 검정 전 준비(가설 고정, 표본 크기 계산)와 검정 후 해석(효과 크기 + p-value)은 사람이 챙겨야 합니다. "사전 표본 크기 계산 → 가설 고정 → 데이터 수집 → 검정 → 효과 크기와 함께 해석"이 신뢰할 수 있는 A/B 테스트의 흐름입니다. 다음 글에서는 AI가 상관을 인과로 잘못 읽을 때 어떻게 다뤄야 하는지를 다룹니다.
