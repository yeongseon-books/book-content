# 바이브코딩을 위한 통계 기초 (2/10): AI가 평균을 잘못 골랐을 때 — 평균·중앙값·분산

이 글은 바이브코딩을 위한 통계 기초 시리즈의 2번째 글입니다.

AI에게 "이 데이터의 대표값을 구해줘"라고 하면 대부분의 경우 평균을 반환합니다. 빠르고 익숙한 계산이기 때문입니다. 그런데 결제 금액 데이터에서 AI가 내놓은 "평균 결제액 50달러"라는 숫자를 팀에 공유했더니, 실제 대부분의 사용자는 10~15달러 구간에 몰려 있었습니다. 소수의 고액 결제가 평균을 크게 끌어올린 것입니다.

바이브코딩 환경에서 AI는 계산을 빠르게 해주지만, 어떤 대표값이 이 데이터에 적합한지는 사람이 판단해야 합니다. AI에게 "평균 대신 중앙값을 써야 하는 경우를 먼저 확인해줘"라고 요청하지 않으면, AI는 기본값으로 평균을 사용합니다.

평균과 중앙값의 차이는 계산 방법의 차이가 아닙니다. 데이터 모양에 따라 어떤 숫자가 실제 사용자의 전형적인 경험을 더 잘 대표하는가의 문제입니다. 여기에 분산과 IQR을 더하면 AI가 내놓은 요약 통계가 데이터를 얼마나 잘 설명하는지 바로 검증할 수 있습니다.

> 요약 통계는 맞는 숫자 하나가 아니라, 데이터 모양에 맞는 조합을 고르는 판단입니다.

## 이 글에서 다룰 문제
- AI가 평균을 반환했을 때 그 숫자를 그대로 써도 되는지 어떻게 판단할까요?
- 평균과 중앙값 중 어떤 상황에서 무엇을 선택해야 할까요?
- 분산과 표준편차는 AI 결과의 신뢰도를 어떻게 드러낼까요?
- 극단값이 하나 섞였을 때 요약 통계는 어떻게 달라질까요?
- IQR은 표준편차와 어떻게 다른 정보를 줄까요?

## 평균·중앙값·분산의 바이브코더 관점

AI에게 데이터 요약을 요청할 때 대표값 선택의 기준을 명시하지 않으면 아래처럼 흘러갑니다.

| 지표 | 언제 쓰는가 | 이상치 민감도 | AI 요청 예시 |
|---|---|---|---|
| 평균 | 데이터가 대칭이고 이상치가 없을 때 | 높음 | "응답 시간의 평균을 구해줘" |
| 중앙값 | 긴 꼬리나 이상치가 있을 때 | 낮음 | "결제 금액의 중앙값을 구해줘" |
| 최빈값 | 범주형 데이터나 뚜렷한 봉우리가 있을 때 | 낮음 | "가장 많이 선택된 요금제를 알려줘" |

AI에게 요청할 때 분포 확인을 먼저 시키면 대표값 선택 실수를 줄일 수 있습니다: "히스토그램을 먼저 그리고, 극단값이 있으면 중앙값을 중심으로 요약해줘."

## 분산과 표준편차 — AI 결과의 흔들림 확인

분산은 데이터가 평균에서 얼마나 떨어져 있는지를 제곱 거리로 평균 낸 값입니다. 표준편차는 그 제곱근으로 원래 단위와 같아서 더 직관적입니다.

AI가 두 그룹의 평균이 같다고 보고하더라도, 표준편차가 크게 다르면 두 그룹은 완전히 다른 데이터입니다. 이 점을 확인하지 않으면 AI의 요약을 그대로 믿다가 잘못된 결정을 내릴 수 있습니다.

```python
import numpy as np

# 두 반의 시험 점수
class_a = np.array([68, 70, 69, 72, 71, 70, 69, 71, 70, 70])
class_b = np.array([50, 90, 60, 80, 70, 65, 75, 85, 55, 70])

print("A반 평균:", class_a.mean(), "표준편차:", class_a.std())
print("B반 평균:", class_b.mean(), "표준편차:", class_b.std())
```

A반과 B반의 평균은 70으로 동일하지만 표준편차는 10배 이상 차이납니다. AI가 "두 반의 평균이 같습니다"라고 보고할 때, 이 표준편차 차이를 함께 확인하지 않으면 완전히 틀린 해석을 하게 됩니다.

## Before / After

**Before**: AI에게 결제 금액 데이터를 넘기며 "평균 결제액을 구해줘"라고 합니다. AI가 "평균 50달러"라고 반환합니다. 이 숫자로 가격 정책을 세웠는데, 실제 대부분의 사용자는 12달러 구간에 있었습니다.

**After**: AI에게 "결제 금액의 히스토그램을 먼저 그리고, 극단값이 있으면 평균과 중앙값을 둘 다 보고하고 어떤 값이 대표값으로 더 적합한지 설명해줘"라고 요청합니다. AI가 "중앙값 12달러, 평균 50달러 — 소수의 고액 결제가 포함된 긴 꼬리 분포이므로 대표값은 중앙값이 적합합니다"라고 답합니다.

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| AI 기본값(평균)을 그대로 사용 | 긴 꼬리 분포에서 평균은 실제 중심을 벗어남 | 분포 확인 후 대표값 선택 지시 |
| 표준편차 없이 평균만 보고 | 두 그룹이 같아 보여도 실제로 다를 수 있음 | 평균과 표준편차를 항상 함께 요청 |
| IQR과 표준편차 혼동 | 극단값이 있으면 표준편차가 과대 추정됨 | 긴 꼬리 데이터엔 IQR 추가 요청 |
| 단위 없이 숫자만 보고 | 달러인지, 초인지, 퍼센트인지 알 수 없음 | AI에게 단위 포함 보고 지시 |

## AI에게 통계 관련 질문하는 팁

AI에게 요약 통계를 요청할 때 이 구조를 사용하면 대표값 선택 실수를 줄일 수 있습니다:

1. **분포 먼저 확인**: "히스토그램을 그리고 왜도를 확인해줘"
2. **이상치 점검**: "극단값이 있는지 IQR 기준으로 확인해줘"
3. **대표값 선택 근거 요청**: "평균과 중앙값 중 어떤 값이 더 적합한지 설명해줘"
4. **퍼짐 지표 함께 보고**: "표준편차와 IQR을 함께 보고해줘"
5. **단위 포함**: "단위(달러, 밀리초 등)를 명시해서 보고해줘"

## 운영 체크리스트
- [ ] AI가 반환한 평균이 이 데이터에 적합한 대표값인지 확인합니다
- [ ] 긴 꼬리 분포나 이상치가 있을 때 중앙값을 우선 검토합니다
- [ ] 표준편차와 IQR을 함께 요청해 퍼짐을 확인합니다
- [ ] AI 결과에 단위가 포함되어 있는지 확인합니다
- [ ] 두 그룹 비교 시 평균만이 아니라 분산도 함께 봅니다

## 처음 질문으로 돌아가기

"AI가 평균을 반환했을 때 그 숫자를 그대로 써도 되는지 어떻게 판단하나요?"

히스토그램을 먼저 확인합니다. 데이터가 대칭에 가깝고 이상치가 없으면 평균을 써도 됩니다. 긴 꼬리가 있거나 이상치가 보이면 중앙값이 더 적합합니다. AI에게 "분포를 먼저 확인하고 대표값 선택 근거를 함께 보고해줘"라고 요청하는 것이 가장 빠른 방법입니다.

## 정리

평균, 중앙값, 분산은 모두 데이터를 요약하지만 같은 역할을 하지 않습니다. AI가 기본값으로 평균을 반환할 때 분포를 먼저 확인하고, 긴 꼬리 데이터에서는 중앙값과 IQR로 검증하는 습관이 바이브코딩 환경에서 통계 오류를 막는 가장 빠른 방법입니다. 다음 글에서는 AI가 분포를 잘못 가정했을 때 생기는 문제를 다룹니다.
