# 바이브코딩을 위한 머신러닝 기초 (2/10): 지도학습 vs 비지도학습 — AI에게 어떤 유형인지 말해줘야

이 글은 바이브코딩을 위한 머신러닝 기초 시리즈의 2번째 글입니다.

AI에게 "고객 데이터 분석해줘"라고 요청했습니다. AI가 코드를 뚝딱 만들어 줬고 실행했더니 뭔가 숫자가 나왔습니다. 그런데 그 숫자가 정확도인지, 군집 개수인지, 유사도 점수인지 맥락이 보이지 않았습니다. 나중에 알고 보니 AI는 군집화(KMeans)를 썼는데, 내가 원한 건 "이탈할 고객인지 아닌지 예측"하는 분류 모델이었습니다.

바이브코딩에서 이런 엇갈림이 자주 발생합니다. AI는 요청에서 단서를 찾아 알고리즘을 고릅니다. "고객 분석"이라는 말은 지도학습일 수도 있고 비지도학습일 수도 있습니다. 내가 먼저 어떤 유형의 문제인지 알아야 AI에게 정확하게 요청할 수 있습니다.

지도학습과 비지도학습의 경계는 딱 하나입니다. 정답 데이터(레이블)가 있는지 없는지입니다. 이탈 여부를 담은 컬럼이 있다면 지도학습, 그런 컬럼 없이 패턴만 찾아야 한다면 비지도학습입니다. 이 구분을 AI에게 명시하면 엉뚱한 알고리즘이 나올 가능성이 크게 줄어듭니다.

> AI가 올바른 알고리즘을 고르려면, 내가 먼저 레이블이 있는 문제인지 없는 문제인지 알고 있어야 합니다.

---

## 이 글에서 다룰 문제
- 지도학습과 비지도학습의 차이를 AI 요청에 어떻게 반영해야 할까요?
- 분류와 회귀는 모두 지도학습인데 AI에게 어떻게 구분해서 요청할까요?
- 군집화 결과가 나왔을 때 그게 좋은 결과인지 어떻게 판단할까요?
- AI가 선택한 알고리즘이 내 문제 유형에 맞는지 확인하는 방법은?
- 레이블이 일부만 있을 때 어떤 방식을 써야 할까요?

## ML 패러다임 비교

| 유형 | 레이블 | 목표 | AI 요청 예시 |
|---|---|---|---|
| 분류 | 있음 (범주) | 이산 레이블 예측 | "이탈 여부 0/1 예측 모델 만들어줘" |
| 회귀 | 있음 (숫자) | 연속값 예측 | "집값 예측 회귀 모델 만들어줘" |
| 군집 | 없음 | 비슷한 것 묶기 | "레이블 없이 고객 그룹 나눠줘" |
| 차원축소 | 없음 | 피처 압축 | "고차원 피처를 2D로 시각화해줘" |

패러다임을 잘못 전달하면 AI가 아무리 좋은 코드를 만들어도 처음부터 틀린 방향으로 갑니다.

## 바이브코딩에서 유형 판단 체크

AI에게 요청하기 전에 이 두 가지를 먼저 확인합니다.

**1단계: 레이블이 있는가?**
- 예측하려는 정답 컬럼이 데이터에 있다 → 지도학습
- 정답 없이 패턴이나 구조를 찾고 싶다 → 비지도학습

**2단계: 지도학습이라면 예측 대상이 무엇인가?**
- 범주(스팸/정상, 이탈/유지, 암/정상) → 분류(Classification)
- 숫자(가격, 온도, 매출액) → 회귀(Regression)

이 두 질문에 답할 수 있으면 AI 요청 문장이 훨씬 명확해집니다.

## Before / After

**Before**: "고객 데이터 분석해줘" → AI가 KMeans 군집화 코드를 만들어 줬지만 원하던 이탈 예측이 아니었습니다.

**After**: "고객 데이터에서 churn 컬럼(0/1)을 예측하는 분류 모델 만들어줘. 로지스틱 회귀로 시작해줘." → 원하는 모델이 나왔습니다.

## AI가 만든 유형별 코드 비교

**지도학습 - 분류 예시:**
```python
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(max_iter=1000).fit(X, y)
print("acc:", clf.score(X, y))  # 레이블이 있어서 정확도 계산 가능
```

**비지도학습 - 군집화 예시:**
```python
from sklearn.cluster import KMeans
km = KMeans(n_clusters=3, n_init=10).fit(X)
print("inertia:", km.inertia_)  # 레이블 없음, 응집도로 평가
```

두 코드의 `score`와 `inertia_`는 완전히 다른 개념입니다. 숫자 크기를 직접 비교하는 건 의미가 없습니다. 비지도학습에서는 "더 좋다"는 판단이 훨씬 어렵습니다. 정답이 없기 때문입니다.

## 바이브코딩할 때 자주 하는 실수

| 실수 | 왜 문제인가 | 해결 |
|---|---|---|
| 유형 명시 없이 "분석해줘" 요청 | AI가 임의로 알고리즘 선택 | 지도/비지도, 분류/회귀 명시 |
| 군집 결과를 정답 레이블처럼 사용 | 군집은 가설이지 정답이 아님 | 결과를 가설로 다루고 별도 검증 |
| 회귀 문제에 분류 코드 적용 | 연속값을 범주로 취급하면 정보 손실 | 예측 대상 유형 먼저 확인 |
| KMeans 결과 inertia를 정확도처럼 해석 | 지표 의미가 완전히 다름 | 비지도 지표(실루엣 등) 의미 파악 |

## AI에게 ML 관련 질문하는 팁

**좋은 요청 패턴:**
- "레이블이 있는 분류 문제입니다. y 컬럼이 0과 1입니다. 로지스틱 회귀로 시작해줘."
- "레이블 없이 고객 세그먼트를 나누고 싶습니다. KMeans로 군집화해줘."
- "연속값 예측 회귀 문제입니다. 선형 회귀로 베이스라인 잡아줘."

**AI가 선택한 알고리즘 확인하는 질문:**
- "이 코드가 지도학습인가요, 비지도학습인가요?"
- "레이블이 필요한 알고리즘인가요?"
- "이 문제를 분류로 접근했는데, 회귀로 접근하면 어떤 차이가 있나요?"

## 운영 체크리스트
- [ ] 레이블 유무로 지도/비지도 구분을 할 수 있습니다
- [ ] 분류와 회귀의 차이를 한 문장으로 설명할 수 있습니다
- [ ] AI에게 ML 유형을 명시해서 요청할 수 있습니다
- [ ] 군집화 결과를 정답이 아니라 가설로 취급할 수 있습니다
- [ ] 지도학습 지표(정확도)와 비지도학습 지표(inertia)의 차이를 압니다

## 처음 질문으로 돌아가기

- **AI가 엉뚱한 알고리즘을 선택하지 않으려면?**
  - 레이블 유무와 문제 유형(분류/회귀/군집)을 요청에 명시하면 됩니다.
- **분류와 회귀를 어떻게 구분해서 요청하나요?**
  - 예측 대상이 범주(스팸/정상, 이탈/유지)면 분류, 숫자(가격, 매출)면 회귀라고 말해주면 됩니다.
- **군집화 결과가 좋은지 어떻게 아나요?**
  - 정답이 없으므로 실루엣 점수, 엘보 방법, 도메인 지식으로 종합 판단해야 합니다.
- **AI가 선택한 알고리즘이 맞는지 확인하는 방법은?**
  - "이 알고리즘이 레이블이 있는 문제에 쓰는 건가요?"라고 직접 물어보면 됩니다.
- **레이블이 일부만 있을 때는 어떻게 하나요?**
  - 준지도학습 방식을 쓰거나, 레이블 있는 부분만 지도학습으로 처리하는 방법을 AI에게 물어볼 수 있습니다.

## 정리

바이브코딩에서 AI가 올바른 ML 코드를 만들려면, 내가 먼저 문제 유형을 알고 전달해야 합니다. 레이블이 있으면 지도학습, 없으면 비지도학습. 지도학습에서 예측 대상이 범주면 분류, 숫자면 회귀. 이 두 가지 판단만 명확해도 AI와의 ML 작업 방향이 처음부터 맞아떨어집니다.
